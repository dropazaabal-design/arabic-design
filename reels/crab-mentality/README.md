# عقلية السلطعون — ريل ٩:١٦

ريل قصصي متحرّك (١٠٨٠×١٩٢٠، ٣٠ إطارًا/ث، ٥١٫٨ ث) عن التثبيط بوصفه **استعارة لا
تشخيصًا**: سلطعون أزرق يحاول الخروج من السطل، ومخلب أحمر يشدّه، ثم يبني سُلّمه
بثلاث خطوات ويخرج. عامية مغربية، هوية «كتاب وبس» (كحلي #101827، أزرق #2E7BC5،
أحمر #E63946، عاجي #F5F1E8)، رسوم رمزية بلا وجوه.

الملف: `out/crab-mentality.mp4` — H.264 (yuv420p) + AAC 48 kHz.

## المسار كما جرى فعلًا

| المرحلة | الأداة | ما حدث |
|---|---|---|
| تحليل المرجع | قراءة المراجعة المرفقة | الصراع في أول ثانية، والاسم قبل ١٤ ث، وثلاث خطوات عملية، وخروج بصري في الخاتمة |
| التخطيط | **بصيرة** `canva_build_reel` (خادم MCP المحلّي) | خطّة ٩ مشاهد: خطّاف أولًا، حدود الكلمات، الترتيب. بوّابة جودتها **فشلت بـ٢٧ خطأ** لأنها لوّنت المشاهد بالبرتقالي (#F5B83D) رغم هوية «كتاب وبس»، ومشاهدها بطاقات ثابتة؛ فأُخذت الخطّة بنيةً، لا مظهرًا |
| الأصول | **بصيرة** — مكتبة البداية | لا مكتبة مستخدم في هذه البيئة (`~/.baseera` غير موجود). أُعيد استعمال `notebook-pencil` و`steps-flag` و`lightbulb` بتلوين رموزها (`tools/assets.mjs`)؛ السطل والسلطعون والمخالب والفنجان والسلّم رُسمت SVG جديدة |
| تدقيق العربية ١ | **بصيرة** `studio check` | النصّ المعتمد: ٠ أخطاء، ٠ تحذيرات |
| النطق | `speakable()` (قبل التراجع عن PR #3) | ١٤ مقطعًا بلا تحذيرات؛ النتيجة محفوظة في `speak.json` |
| الصوت | **Habibi-TTS**، النسخة المتخصّصة MAR (Apache-2.0) | ١٤ مقطعًا؛ مقطع مرجعي من معيار Habibi (Apache-2.0، المتحدّث 164)، لا صوت صاحب المرجع ولا مقطع ElevenLabs المرفق بالحزمة |
| فحص النطق | faster-whisper medium | «عقلية السلطعون» سُمعت حرفيًا؛ أُعيد توليد مقطعين بثلاث بذور واختير الأوضح، و«انتبه» صارت «رد بالك» |
| الحركة والمزامنة | **Remotion** 4.0.534 | كل حركة مربوطة بالإطار وبمُدد الصوت المقيسة (`src/timeline.json`)؛ لا شيء مقدَّر |
| تدقيق العربية ٢ | **بصيرة** `studio check --source` | النصوص المكتوبة في `src/Reel.tsx` قورنت حرفًا بحرف بالمعتمد: ٠ أخطاء. وتأكّد أن الفحص يلتقط الخطأ: ثلاثة أخطاء مزروعة (ة/ه، شدّة) التُقطت كلّها |
| المراجعة | إطارات من ملف MP4 نفسه + ffprobe | انظر الحالة أدناه |

**Canva لم يُستعمل**: الطلب ريل متحرّك، وموصل Canva بلا حركة ولا صوت. يُبنى إن
أردتَ نسخة تصميم قابلة للتحرير.

## الحالة

| البند | الحالة |
|---|---|
| المشاهد | ٨ مشاهد في عالم واحد متصل (كاميرا، قطع مطابق سطل←فنجان) |
| الملف | مُقاس: H.264 High، yuv420p، AAC 48 kHz ستيريو |
| المقاس | ١٠٨٠×١٩٢٠ مُتحقَّق |
| المدّة | ١٥٥٥ إطارًا = ٥١٫٨٣ ث، مطابقة للخطّة |
| توقيت المشاهد | من مُدد الصوت المقيسة؛ لم يُتحقَّق مشهدًا مشهدًا بكشف القطع لأن الريل بلا قطع صلبة |
| الحركة | داخل الملف، مُراجَعة على إطارات مستخرجة منه |
| الصوت | موجود في الملف، −16.7 LUFS، بلا صمت فوق ثانية إلا الختام المقصود |
| الاستماع البشري | **لم يحدث**: فحص النطق آلي (Whisper غير مدرَّب على الدارجة، فيحوّلها إلى فصحى). استمع قبل النشر |

## إعادة الإنتاج

```bash
npm install
# الصوت (Python، CPU): pip install habibi-tts "torch==2.8.*" "torchaudio==2.8.*"
python tools/voice_habibi.py speak.json ref.wav "<نص المرجع>" public/voice
node tools/timeline.mjs          # المُدد من ffprobe → src/timeline.json
npx remotion studio src/index.ts # معاينة
npm run render                   # → out/crab-mentality.mp4
BASEERA_HOME=… node tools/proof.mjs out/proof   # تدقيق بصيرة للنصوص
```

`speak.json` = مقاطع `script.json` بعد تطبيعها للنطق (`…` ← «،»)، محفوظ هنا كما وُلّد
الصوت منه. وُلّد بـ`speakable()` من `lib/speech.js` الذي سُحب من `main` بالتراجع
عن PR #3، فلا يعتمد عليه هذا المشروع.
سطر أوامر habibi-tts 0.1.1 يرفض MAR (assert ينقصه)، فـ`voice_habibi.py` يحمّل
`Specialized/MAR/model_100000.safetensors` كما يحمّل السطرُ نفسه بقيّة اللهجات.
