# عقلية السلطعون — النسخة ٢

ريل قصصي متحرّك ١٠٨٠×١٩٢٠، ٣٠ إطارًا/ث، بعامية عربية بيضاء وصوت راوٍ محايد،
عن التثبيط بوصفه **استعارة**: سلطعون يحاول الخروج من السطل، والآخرون يشدّونه،
فيبني طريقه درجةً درجة ويخرج.

الملف: `out/crab-mentality.mp4` — ٥٤٫٢ ث، H.264 ‏(yuv420p) + AAC ٤٨ ك.هـ.

## ما تغيّر عن النسخة ١

| مشكلة النسخة ١ | ما صار |
|---|---|
| تكرار الصعود والهبوط والسطل في البداية | محاولة واحدة في ٣ ث (صعود، توقّف، إمساك، شدّ، سحب، ردّ فعل)، ثم كشف المقطع من الداخل، ثم الاستعارة **رسمًا بالحبر على ورقة** — صورة جديدة لا إعادة |
| رسوم وفقاعات صغيرة في فراغ واسع | لقطة قريبة ×٢ للحافة، ومشاهد مكبَّرة (الورشة ×١٫٣، الخطّة ×١٫٣)، وفقاعات ٨٠٠×٢٣٦ |
| تشابه التكوين | لكل جزء بيئته وضوؤه: ليل نيلي وضوء الفتحة، مكتب فيروزي ومصباح، ورشة غسق بنفسجية، شاشة منقسمة، مخطّط أزرق، فجر مرجاني |
| تأخّر فرق النصيحة والتثبيط | الشاشة تنقسم مع أول كلمة؛ الأخضر يحدّد الدرجة المكسورة ويصلحها ويصعد، والأحمر يمسك ويُسقط السلّم — بالفعل والمسار قبل اللون |
| سلّم منفصل عن الأفعال | كل خطوة تصنع **درجة**: القفل يصير درجة، أداة الخبرة تصير درجة، قائمة الإنجاز تُطوى درجة؛ ثم تنتقل الدرجات إلى السطل ويُخرج بها |
| رموز بجانب الكلام | أحداث متسلسلة: الدفتر يُفتح ويُكتب فيه من اليمين ثم تصفعه الفقاعة؛ المظلّة تُركَّب ثم تُكسر؛ الأداة التي يأخذها من الخبرة يصلح بها تعثّره في الخاتمة |
| سكريبت وصوت مغربيان | عامية بيضاء، وصوت محايد (انظر «الصوت») |

## المسار كما جرى فعلًا

| المرحلة | الأداة | ما حدث |
|---|---|---|
| الهوية | **بصيرة** `studio brand` | هوية «كتاب وبس» تمنع الأصفر والبرتقالي؛ سُجّلت نسخة للريل `kitabwbs-crab` (`brand.json`) بالأزرق والأحمر والأخضر ذاتها وبالخطوط ذاتها، وأُضيف الكهرماني والفيروزي والبنفسجي والمرجاني كما أذنت النسخة ٢ |
| التخطيط | **بصيرة** `canva_build_reel` | بهوية «كتاب وبس» الأصلية فشلت البوّابة بـ٢٧ خطأ (لون برتقالي افتراضي)؛ بالنسخة `kitabwbs-crab` نجحت (٠/٠). أُخذ منها: الخطّاف أولًا (٤ كلمات)، وحدود الكلمات، والحركة بالعنصر (`pop` للخطّاف، `rise` للعناوين)، وتناوب الانتقال `push`/`fade` بدل انتقال موحّد |
| المكتبة | **بصيرة** `studio asset` | أُعيد استعمال ثلاث رسوم من مكتبة البداية (دفتر الخطط، المصباح، شارة الدرجات). و١٨ أصلًا جديدًا صُدّرت SVG مستقلة بلا نص (`assets/library/`) وسُجّلت في مكتبة بصيرة بوسم `kitabwbs-crab` |
| التدقيق | **بصيرة** `studio check --source` | كل نص يرسمه `src/Reel.tsx` قورن حرفًا بحرف بالنص المعتمد في `script.json` |
| الصوت | **Habibi-TTS** (مستقل؛ بصيرة بلا أداة صوت) | انظر «الصوت» |
| الحركة | **Remotion** 4.0.534 | كل حركة مربوطة بإطار وبمُدد الصوت المقيسة (`src/beats.ts` ← `src/timeline.json`) |
| الفحص والتصدير | **FFmpeg / ffprobe** | تطبيع الصوت، توليد المؤثرات، قياس الملف، استخراج الإطارات للمراجعة |
| Canva | **لم يُستدعَ** | أدوات موصل Canva ظاهرة في الجلسة ولم تُستدعَ: الموصل لا يحمل حركة ولا صوتًا ولا توقيتًا، فنقل الريل يفقد ما طُلب. الأصول المستقلة والهوية في بصيرة جاهزة لنسخة ثابتة قابلة للتحرير إن أردتها |

## الصوت

- المحرّك: Habibi-TTS 0.1.1، نسخة **Specialized/MSA** ‏(Apache-2.0)، على CPU.
- المرجع: مقطع من معيار Habibi ‏(Apache-2.0)، صف 1055، المتحدّث 165 — لا صوت صاحب المرجع، ولا مقطع ElevenLabs المرفق بالحزمة.
- الاختيار بعيّنة قبل التوليد الكامل: أول جمل الريل ثم أصعب الجمل العامية، على أربعة متحدّثين، بمطابقة Whisper ‏(faster-whisper medium) والإيقاع وحركة النبرة والوقفات. التفاصيل في `voice.json`.
- الإعدادات ثابتة لكل المقاطع: مرجع واحد، سرعة ١٫٠٦، بذرة ٧؛ والمقاطع المعادة بسرعة ١٫٠ وبذرة ٢١ أو ٤٢.
- مفردات النسخة لا تعرف «، ؛ ؟» ولا الشدّة والتنوين: تُحوَّل العلامات إلى `, , ?` لتبقى الوقفات، وتُحذف الشدّة والتنوين صراحة.
- كل مقطع يُطبَّع إلى −16 LUFS بكسب ثابت (`tools/normalize-voice.sh`).
- **لم يستمع إنسان**: الفحص آلي. استمع قبل النشر، وخاصّة لِلَكنة واتّساق الصوت.

## المشاهد والتوقيت

الأزمنة من مُدد الصوت المقيسة (`src/timeline.json`)، وكل لحظة حركة مربوطة بمقطعها في `src/beats.ts`.

| المشهد | الزمن | التعليق | ما يحدث |
|---|---|---|---|
| 1 | 0.0–3.1 ث | كل ما تحاول تتقدّم… في أحد يرجّعك خطوة. | محاولة واحدة: صعود بالمخالب، توقّف أمام الضوء، مخلب أحمر يمسك، شدّ يمدّ الجسم، سحب سريع، ارتجاج وخدوش |
| 2 | 3.1–10.5 ث | أحيانًا الطريق مفتوح، لكن بعض اللي حولك يحاولون يوقفونك. ولهذه الصورة اسم: عقلية السلطعون. | الجدار يصير شفافًا: السحب من سلطعونات حمراء في القاع، وضوء الفتحة مفتوح؛ دفع نحو العقدة |
| 3 | 10.5–17.8 ث | تخيّل سلطعون يحاول يطلع من سطل… والبقية يسحبونه لتحت. هي مجرد استعارة… لكنها تتكرر بيننا. | «تخيّل»: لقطة أوسع ثم المشهد رسمًا بالحبر على ورقة مثبّتة — مسار أزرق للمحاولة وأسهم حمراء للسحب؛ ثم يتحوّل السطل إلى فنجان |
| 4 | 17.8–23.0 ث | تقول: راح أتعلّم مهارة. يرد عليك: وحتى اللي تعلّموا، ماذا حققوا؟ | مكتب ومصباح: يخرج من الفنجان، يفتح دفترًا عربيًا (الغلاف يمينًا)، يكتب من اليمين؛ فقاعة تصفع الدفتر وتطيّر القلم |
| 5 | 23.0–26.3 ث | تبدأ مشروع صغير. يقول لك: خفّف أحلامك. | ورشة غسق: صناديق تسقط، مظلّة وأضواء، شارة الدرجات؛ «خفّف أحلامك» تكسر المظلّة وحدها |
| 6 | 26.3–34.9 ث | لكن انتبه: بعض الانتقاد يساعدك. النصيحة توضّح الخطأ، وتعطيك طريقة تصلحه. والتثبيط يوقف المحاولة من البداية. | شاشة منقسمة: النصيحة تحدّد الدرجة المكسورة وتصلحها فيصعد (مسار أخضر)، والتثبيط يمسك ويُسقط السلّم (مسار أحمر) |
| 7 | 34.9–46.2 ث | كيف تتعامل معه؟ قلّل مشاركة خططك مع اللي يحبطك. اسأل شخص عنده تجربة. وقِس تقدّمك بما تنجزه. راقب أثر الكلام، ولا تتسرّع في الحكم على النوايا. | مخطّط أزرق: القفل يصير درجة، أداة الخبرة تصير درجة، قائمة الإنجاز تُطوى درجة؛ مسطرة؛ يصعد، يأخذ الكلام المفيد درابزينًا ويترك الثقيل يسقط |
| 8 | 46.2–54.2 ث | وإذا تعثّرت، عدّل طريقتك وواصل. خروجك يبدأ بخطوة منك… ما يحتاج موافقة السطل. | الدرجات داخل السطل: يتعثّر، يعدّل بالأداة، يواصل، يخطو إلى الحافة؛ المخالب تُطبق على الفراغ؛ يهبط خارج السطل مع الفجر |

النص المعتمد على الشاشة ١٩ سطرًا (`script.json` → `onScreen`)، ونصّ النطق في `speak.json`.

## التحقّق

| البند | النتيجة |
|---|---|
| الملف | H.264 High، yuv420p، ١٠٨٠×١٩٢٠، ٣٠ إطارًا/ث؛ AAC‏ ٤٨ ك.هـ ستيريو |
| المدّة | ١٦٢٧ إطارًا = ٥٤٫٢٣ ث، مطابقة لخطّة التوقيت (١٦٢٧) |
| الصوت في الملف | −16.4 LUFS، ذروة −1.9 dB؛ لا صمت فوق ثانية إلا وقفة الختام (١٫٨ ث) |
| تدقيق بصيرة | ١٩/١٩ نصًّا مطابقًا حرفًا بحرف، ٠ أخطاء؛ وأربعة أخطاء مزروعة (حرف، شكل، تاء مربوطة) التُقطت كلّها |
| بوّابة الريل في بصيرة | ٠ أخطاء بهوية `kitabwbs-crab` |
| النطق (Whisper) | متوسّط مطابقة ٠٫٩٣ بعد الإعادة (كان ٠٫٧٨)؛ «عقلية السلطعون» و«ماذا حققوا» و«خفّف أحلامك» و«موافقة السطل» مسموعة — `voice.json` |
| المراجعة البصرية | إطار كل ثانية من الملف نفسه، ولقطات كاملة للخطّاف والإمساك والمثالين والمقارنة والخطوات والخروج؛ أُصلح منها: تكرار السطل (صار رسمًا على ورق)، تداخل العنوان مع البطاقة والصناديق، ترتيب القطع المطابق، المخالب الطويلة في الخاتمة |
| ما لم يُفحص | الاستماع البشري للّكنة والدفء؛ ولا بيانات مشاهدة أو احتفاظ — «أقوى» حكم تحريري |

## إعادة الإنتاج

```bash
npm install
# الصوت (Python، CPU):
pip install habibi-tts "torch==2.8.*" "torchaudio==2.8.*"
python tools/voice_habibi.py speak.json ref.wav "<نص المرجع>" raw --dialect MSA --speed 1.06 --seed 7
for f in raw/*.wav; do tools/normalize-voice.sh $f public/voice/$(basename $f); done
npm run timeline        # المُدد من ffprobe ← src/timeline.json
npx remotion studio src/index.ts
npm run render          # ← out/crab-mentality.mp4
BASEERA_HOME=… npm run proof    # تدقيق بصيرة للنصوص المرسومة
npm run assets          # أصول المكتبة SVG ← assets/library/
```
