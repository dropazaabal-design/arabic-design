# «لماذا تتمسك بالخسارة؟» — النسخة A (الفيلم المخيّب)

ريل عربي أصلي عن **مغالطة التكلفة الغارقة**: 1080×1920، **60 إطارًا/ث**، 77.75 ث.

القصة: تذكرة بـ150 لفيلم سيئ، ومعضلة الخروج، وزمن يمر في قاعة تفرغ. ثم تغرق التذكرة تحت بابي «تقعد» و«تطلع» معًا، ويأتي الدليل من آركس وبلومر (1985) والاستثناء الصحيح، وينتهي بخروجه إلى أصدقائه.

| ملف | ما هو |
|---|---|
| `output/final_reel.mp4` | الفيديو النهائي |
| `publish/cover-1080x1920.jpg` | الغلاف (Cover بالإطار 1614) |
| `output/captions.ar.srt` | الترجمة |
| `publish/publish.md` | العناوين والكابشنات: يوتيوب، فيسبوك، إنستغرام |
| `output/qa_report.md` | تقرير الجودة التقني والبصري |
| `script.md` | المصدر وما قُرئ منه، والنص المقفول، والصوت |
| `storyboard.md` / `storyboard.src.json` | 15 لقطة مثبتة على الكلمات |
| `src/scene/shots.tsx` | اللقطات |
| `src/scene/kit.tsx` | الشخصية، وأثاث السينما، والإطار |
| `tools/sfx.py` | المؤثرات الأصلية |

## التشغيل

```sh
(cd ../motion && npm ci) && npm ci
npm run voice        # الصوت والتوقيت والترجمة من التسجيل (reels/tools/voice_timeline.py)
npm run sfx          # المؤثرات الأصلية
npm run mix          # الصوت وحده لضبط MIX_GAIN (ثوانٍ)
npm run render       # التصيير النهائي + إعادة الترميز + output/render-time.json
npm run cover
npm run check        # ترتيب الإطارات، وتطابق 30/60، وفك MP4
npm run gates        # بوابات الجودة على الملف النهائي
python3 ../tools/patch_render.py . A-B   # إصلاح صورة في مدى إطارات دون تصيير كامل (الصوت كما هو)
```
