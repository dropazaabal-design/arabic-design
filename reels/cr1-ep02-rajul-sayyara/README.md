# الناس ما يشوفونك في سيارتك — الحلقة الثانية من CR1

**فكرة من كتاب · كتاب وبس** — الحلقة الثانية على مسار CR1 (16 أكتوبر 2026).
الكتاب: «سيكولوجية المال» لمورجان هاوسل (الفصول 7 و8 و9). الفكرة: «مفارقة الرجل في السيارة»، والفرق بين الغنى اللي ينشاف والثروة اللي ما تنشاف، وإيش تشتري الثروة فعلًا: وقتك.
أول حلقة بشخصيات بشرية كرتونية (تصحيح القاعدة في `motion-core/NARRATIVE-DIRECTOR.md`، القاعدة 5): ماجد وسعد وزملاؤهما، وصافّ السيارات من قصة الكتاب. لا صور بشرية واقعية.

## حزمة الحلقة

```
episode-brief.json   الزوايا الثلاث ودرجاتها وسبب الاختيار، الافتتاحيات، الشخصيات، اللوحة، الميزانية والمصروف الفعلي
sources.json         الكتاب والطبعة العربية، سجل الادعاءات C1–C9 (كتاب / دفتر المؤلف / من إعدادنا)، المراجع
script-long.md       النص الطويل المقفل (11 مقطعًا، 514 كلمة)؛ كل سطر = قطعة ترجمة
script-short.md      نص الريل المستقل (6 مقاطع، 136 كلمة)
scene-plan.json      بطاقات المشاهد E1–E11 وS1–S6 وقواعد التكييف لكل مقاس
timeline.json        الوحدات الصوتية المختارة ومواضعها، والمؤثرات وكلماتها، وقياس المزج
sfx.json             المؤثرات، كل واحد مربوط بكلمة وفعل
audio/takes/         كل نسخ ElevenLabs (4 لكل وحدة، ومعها L2 المعاد توليده)
audio/align/         توقيت الكلمات للنسخ المختارة
audio/generations.json  كل توليد بعقدته وجلساته ورصيده
src/                 Remotion: Film.tsx (الحلقة والريل)، scenes/ (مشهد لكل مقطع)، sets.tsx، graphics.tsx، Cover.tsx
tools/               asr.py، takes.py، build_audio.py، verify.py، acceptance.py، copycheck.mjs، fontcheck.py، palette.mjs، stills.mjs، manifest.py
```

طقم الشخصيات نفسه في `motion-core/src/cartoon` (انظر `motion-core/CARTOON.md`): يصلح لأي ريل في المستودع.

## كيف صُنعت

| المرحلة | ما جرى |
|---|---|
| الزاوية | ثلاث زوايا قُيّمت على القرب من حياة المشاهد، والمفارقة، وقابلية الرسم، والعمق، والنقاش. اختيرت «مفارقة الرجل في السيارة ← الثروة اللي ما تنشاف ← الحرية» |
| المرجع البصري | فيديو يوتيوب المرجعي **لم يُشاهَد**: يوتيوب محجوب من بيئة الإنتاج. أخذنا مبادئ عامة لفيديوهات الشرح الكرتونية، لا من المرجع |
| الكتابة | عربية بيضاء قريبة من الخليجية. عبارات هاوسل «بمعنى كلامه». الحدود صريحة: ضيق الدخل مشكلة دخل، والسيارة وحدها لا تقول شيئًا عن صاحبها، والفكرة ليست البخل |
| الصوت | ElevenLabs ‏`eleven_v4`، الصوت `dlGxemPxFMTY7iXagmOj`، 4 نسخ لكل وحدة. الاختيار بالقياس الصوتي (`takes.py`) ثم بتفريغ مستقل (Whisper محليًا، `asr.py`) يغلب القياس حين يسمع كلمة ناقصة |
| النطق | كل نهاية مفرّغة وحدها؛ وحدة L1+L2 كانت مقطوعة فأُعيد L2 وحده. «الغنى» و«الثروة» يسمعهما Whisper ناقصتين؛ اختبار بالتشكيل لم يغيّر السماع، فلم نُعد التوليد ووضعناهما أول قائمة السماع البشري |
| الميزانية | سقف 20000 رصيد بالتفويض. المصروف 15078.49 (انظر `episode-brief.json`) |
| المزج | الصوت ومؤثرات مربوطة بالأفعال، بلا موسيقى؛ كسب واحد إلى −16 LUFS ثم محدد ذروة |
| الحركة | Remotion ‏4.0.534 بـ60 إطارًا. كل حركة مربوطة بكلمة منطوقة (`timing().at(seg, i, check)`)؛ الشخصيات تنظر وتتردد وتخجل وتقرر |
| التكييف | 16:9: الحدث أفقي والعنوان فوقه. 9:16 و4:5: كاميرا أقرب، والمخططات مكدسة رأسيًا في عمود آمن فوق الترجمة؛ كل مشهد أعيد تأطيره لكل مقاس |

## التشغيل

```sh
npm install
python3 tools/build_audio.py         # يعيد بناء المزج والتوقيت والترجمة من النسخ المختارة (لا توليد جديد)
node tools/palette.mjs && node tools/copycheck.mjs && python3 tools/fontcheck.py
npx tsc --noEmit -p .
npm run studio                        # المعاينة
REMOTION_CHROME=… npx remotion render Episode16x9 export/…_16x9_v1.0.0.mp4 --crf=12 --x264-preset=slow --audio-codec=aac --audio-bitrate=192k
python3 tools/verify.py export/…_16x9_v1.0.0.mp4 long 1920x1080
```

إصلاح موضعي: تغيير نص مقطع يعني توليد تلك الوحدة وحدها، ثم `build_audio.py`، ثم إعادة تصيير المقاسات التابعة لها فقط.
