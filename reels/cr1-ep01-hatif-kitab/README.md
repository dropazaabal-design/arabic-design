# لماذا الهاتف أقرب من الكتاب؟ — الحلقة التجريبية لـ CR1

**فكرة من كتاب · كتاب وبس** — الحلقة الأولى على مسار CR1 الإصدار 2.0 (15 أكتوبر 2026).
الكتاب: «العادات الذرية» لجيمس كلير. الفكرة: اجعل إشارة العادة المرغوبة ظاهرة في المكان.
الموقف: مكتب ليلًا، هاتف مضاء عليه وكتاب داخل الدرج. لا وجوه ولا أشخاص: الحكاية تُروى بالأشياء.

## حزمة الحلقة (CR1 §10)

```
episode-brief.json   بطاقة الفكرة، الافتتاحيات الثلاث وسبب الاختيار، اللوحة، الميزانية
sources.json         الكتاب والمقتطف، سجل الادعاءات C1–C7، مراجع المنصات، تراخيص الأصول
script-long.md       النص الطويل المقفل (8 مقاطع)؛ كل سطر = قطعة ترجمة
script-short.md      نص الريل المستقل (6 مقاطع)
scene-plan.json      بطاقات المشاهد: الوضع الأولي، الحدث، التحول، الربط، التزامن، التكييف
timeline.json        الوحدات الصوتية المختارة ومواضعها، والمؤثرات وكلماتها، وقياس المزج
render-profiles.json المقاسات ومناطق الأمان وأحجام النص وإعدادات الترميز
sfx.json             المؤثرات القليلة، كل واحد مربوط بكلمة وفعل
audio/takes/         النسخ الأربعون من ElevenLabs (4 لكل وحدة)
audio/align/         توقيت الكلمات للنسخ العشر المختارة
src/                 مشروع Remotion: art.tsx (المكتب والأشياء)، Episode.tsx، Reel.tsx، text.tsx
tools/               takes.py، build_audio.py، verify.py، copycheck.mjs، fontcheck.py، palette.mjs، stills.mjs، manifest.py
```

## كيف صُنعت

| المرحلة | ما جرى |
|---|---|
| البحث | بطاقة فكرة وسجل ادعاءات. لا أرقام ولا دراسات. رقم الفصل لا يُذكر في الحلقة لأن صفحة المقتطف لم تُفتح من بيئة الإنتاج (انظر `sources.json`) |
| الكتابة | نص طويل 434 كلمة ونص قصير مستقل 138 كلمة، بعربية بيضاء. مرّا على مدقّق المستودع (`lib/spelling.js`، `lib/copy.js`): لا ملاحظات سوى ثلاث كلمات محكية خارج المعجم |
| الصوت | ElevenLabs ‏`eleven_v4`، الصوت المعتمد `dlGxemPxFMTY7iXagmOj`. عينة أولًا (L1 وL3) أُرسلت لصاحب القناة مع الميزانية ففوّض المتابعة، ثم 8 وحدات للحلقة ووحدتان للريل، 4 نسخ لكل وحدة. الاختيار بقياسات تقوم مقام السماع (`tools/takes.py`): الإيقاع، والوقفات عند الترقيم، وتقارب الطبقة والمستوى بين الوحدات، وغياب النقرات |
| التوقيت | توقيت كل كلمة من محاذاة ElevenLabs للنسخة المختارة، وكل كلمة بعد وقفة مثبّتة على بداية الصوت المقيسة؛ الوحدات تُقص داخل صمتها وتوصل بصمت. لا تسريع ولا إبطاء ولا تغيير طبقة |
| المزج | الصوت ومؤثرات قليلة مربوطة بالأفعال، بلا موسيقى؛ كسب واحد إلى −16 LUFS ثم محدد ذروة |
| الحركة | Remotion ‏4.0.534 بـ60 إطارًا. كل حركة مربوطة بكلمة منطوقة؛ المكتب واحد في الحلقة كلها والمقاسات الثلاثة |
| التكييف | 16:9: الغرفة في الوسط، تنزاح لتترك اليمين للبطاقة والخطوات، و«قبل/بعد» جنبًا إلى جنب. 9:16: المكتب بعرض الإطار، شريط قراءة فوقه وترجمة تحته، والحالتان بالتتابع. 4:5: كاميرا أقرب وبطاقة الكتاب في شريط مستقل |

## التشغيل

```sh
npm install
python3 tools/build_audio.py         # يعيد بناء المزج والتوقيت والترجمة من النسخ المختارة (لا توليد جديد)
node tools/palette.mjs && node tools/copycheck.mjs && python3 tools/fontcheck.py
npx tsc --noEmit -p .
npm run studio                        # المعاينة
REMOTION_CHROME=… npx remotion render src/index.ts Episode16x9 export/…_16x9_v1.0.0.mp4 --codec=h264 --pixel-format=yuv420p --color-space=bt709 --crf=12 --x264-preset=slow --audio-codec=aac --audio-bitrate=192k
python3 tools/verify.py export/…_16x9_v1.0.0.mp4 long 1920x1080
```

إصلاح موضعي: تغيير نص مقطع يعني توليد تلك الوحدة وحدها، ثم `build_audio.py`، ثم إعادة تصيير المقاسات التابعة لها فقط. تعديل الكابشن في `publish/platforms.md` لا يعيد الفيديو.
