# الفيديوهات A وB وC (9:16، 60fps، بلا تعليق صوتي)

- **A «ضحكوا عليه…»** (15.5 ثانية):
  - إعادة عربية لقصة الريل المرجعي، برسم جديد وموسيقى أصلية.
  - الطوب الذي يرمونه عليه مكتوب عليه ما قالوه، فيقلبه ويبني به برجه: الشغل، ثم التعلّم، ثم الصبر، ثم الاستمرار، ثم النجاح.
  - النهاية جديدة: لمّا وصل لم يردّ عليهم بالمثل، بل نزّل لهم سلّمًا وصعد أولهم. واستُبدلت بها لقطة المرجع الأخيرة غير المحترمة.
- **B «النخلة»** (18 ثانية):
  - قصة جديدة؛ جدّ يزرع فسيلة، وحفيده يسأله: «متى بتاكل منها؟».
  - يمرّ أربعون عامًا في ستة أيام وليالٍ.
  - يأكل الحفيد من تمرها، ثم يزرع بعصا جدّه، وتسأله ابنته السؤال نفسه.
  - ينتهي حيث بدأ ليُعاد تلقائيًا.

- **C «الضربة 101»** (16 ثانية):
  - رجل أمام صخرة تملأ السماء، يضربها 100 مرة بلا أثر، وتترك كل ضربة علامة.
  - تمرّ الأيام ويقول له الناس «ضيّعت عمرك».
  - الضربة 101 تقع حيث وقعت الأولى، فيمرّ الشق في كل العلامات وتسقط الصخرة، ويظهر أول لون في الفيلم.
  - ثم يمشي إلى صخرة أخرى ويرفع المطرقة، فيعود إلى الإطار الأول.
  - طُبّقت فيه أساليب استخرجناها من مكتبة `library/awesome-opus5-5-videos`:
    - رمادي كله حتى نقطة التحوّل، ثم يدخل اللون؛
    - عدّاد يجعل مرور الوقت مرئيًا؛
    - صمت قبل الذروة؛
    - لكل صوت سبب يُرى على الشاشة؛
    - تكرار بالبناء: الصوت الذي يتجاوز النهاية يُلفّ إلى البداية.
  - الموسيقى من مقام الكرد للمحاولة، ثم العجم مع اللون.

الريل المرجعي لا يُحفظ في المستودع ولا يُعاد نشره.

## إعادة البناء
```bash
ln -s ../cr1-ep04-saa-w-akhallis/node_modules node_modules   # أو npm ci
python3 tools/beats.py    # الخط الزمني
python3 tools/music.py    # الموسيقى والمؤثرات (−16 LUFS، حد −4.5 dBTP)
export REMOTION_CHROME=$(ls -d /opt/pw-browsers/chromium_headless_shell-*/*/headless_shell | head -1)
npx remotion render A export/viral-a_dahikou_9x16_v1.0.0.mp4 --crf=14 --x264-preset=slow --audio-codec=aac --audio-bitrate=192k --browser-executable=$REMOTION_CHROME
npx remotion render B export/viral-b_nakhla_9x16_v1.0.0.mp4 --crf=14 --x264-preset=slow --audio-codec=aac --audio-bitrate=192k --browser-executable=$REMOTION_CHROME
npx remotion render C export/viral-c_darba101_9x16_v1.0.0.mp4 --crf=14 --x264-preset=slow --audio-codec=aac --audio-bitrate=192k --browser-executable=$REMOTION_CHROME
for c in A B C; do npx remotion still Cover$c publish/cover_$(echo $c | tr ABC abc)_9x16.jpg --image-format=jpeg --jpeg-quality=92 --browser-executable=$REMOTION_CHROME; done
node tools/palette.mjs && python3 tools/fontcheck.py
```

## البنية
- `src/rig.tsx`: الشخصية الظلية:
  - الساقان تصلان إلى القدمين بـ IK، والذراعان بزوايا أو بهدف لليد.
  - خيار الثوب والغترة واللحية والكعكة.
  - ما تمسكه اليد لا ينقلب مع الشخصية، فلا تظهر الكلمات معكوسة.
- `src/a/A.tsx`: الحشد، ورشقة الطوب، والإمساك، والبرج، والقمة، والصمت، والسلّم.
- `src/b/B.tsx`: الحفر، والزرع، والسنين، والظل، والزرع من جديد، والسؤال.
- `src/c/C.tsx`: الضربات والعلامات، والعدّاد، والمارّة، والصمت، والشق في شجرة تمرّ بكل العلامات، وسقوط الشظايا، والوادي، والصخرة التالية.
- `src/covers.tsx`: الأغلفة الثلاثة.
- `tools/music.py`:
  - A: لحن السخرية «صول-مي-لا-صول-مي» على الضحكات، ونبض يتسارع، وكل طوبة تُوضع تعلو نغمة، وضربة عند القمة، ثم صمت، ثم ري الكبير مع السلّم.
  - B: نقر يشبه العود على مقام الحجاز، وطبلة إطار، وتكّة لكل سنة في العدّاد.
  - C: دقّة حجر لكل ضربة، وكل رابعة تصعد درجة في الكرد، ثم صمت فيه نَفَس ونبض، ثم انفجار الضربة 101، وتشقّق، وانقلاب إلى العجم مع اللون. الطنين الذي يبدأ عند الثانية 15 يُلفّ إلى البداية، فلا يُسمع موضع الإعادة.
