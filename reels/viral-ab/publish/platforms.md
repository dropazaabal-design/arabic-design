## الفيديو A: «ضحكوا عليه…»

**العنوان**
```
ضحكوا عليه… فنزّل لهم سلّم
```
بدائل:
- `كل طوبة رموها عليه… صارت درجة`
- `رموه بـ«فاشل»… فبنى فيها`

**يوتيوب شورتس: الوصف**
```
ضحكوا عليه، ورموه بالكلام: فاشل، مستحيل، ما بتقدر…
فمسك كل طوبة، وقلبها، وبنى فيها.
ولما وصل، ما ردّ عليهم بالمثل… نزّل لهم سلّم.

#تحفيز #نجاح #كتاب_وبس
```

**إنستغرام وفيسبوك (ريلز)**
```
كل طوبة رموها عليه… صارت درجة 🧱

ضحكوا عليه، ورموه بـ«فاشل» و«مستحيل»… فقلبها وبنى فيها.
ولما وصل، ما ردّ عليهم بالمثل… نزّل لهم سلّم.

مين أول واحد بتنزّل له سلّم لما توصل؟ 👇

#تحفيز #نجاح #كتاب_وبس
```

**X وتيك توك**
```
رموه بـ«فاشل» و«مستحيل»… فبنى فيها.
ولما وصل، نزّل لهم سلّم 🧱
```

## الفيديو B: «النخلة»

**العنوان**
```
«يا جدّي… متى بتاكل منها؟»
```
بدائل:
- `زرعوا فأكلنا… ونزرع فيأكلون`
- `ما أكل منها… بس إحنا أكلنا`

**يوتيوب شورتس: الوصف**
```
جدّ يزرع فسيلة نخل، وحفيده يضحك: «متى بتاكل منها؟»
تمرّ السنين. يكبر الحفيد، ويأكل من تمرها في ظلها، ثم يأخذ عصا جدّه ويزرع من جديد.
زرعوا فأكلنا… ونزرع فيأكلون.

#زرعوا_فأكلنا #نخلة #كتاب_وبس
```

**إنستغرام وفيسبوك (ريلز)**
```
«يا جدّي… متى بتاكل منها؟» 🌴

ما أكل منها هو… أكلنا منها إحنا.
زرعوا فأكلنا، ونزرع فيأكلون.

إيش «النخلة» اللي زرعها لك أحد قبل لا تكبر؟ 👇

#زرعوا_فأكلنا #نخلة #كتاب_وبس
```

**X وتيك توك**
```
زرع نخلة وهو عارف إنه ما بياكل منها 🌴
زرعوا فأكلنا… ونزرع فيأكلون.
```
