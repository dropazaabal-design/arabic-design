# ريل كتاب وبس — ليس كل سؤال يحتاج شرحًا

ريل رأسي أصلي مستوحى من صورة النقاط السبع التي أرسلها صاحب الحساب. محور القصة: اختيار ما نشاركه ومع من، مع إبقاء طلب الدعم متاحًا.

- 1080×1920، 60fps، 42 ثانية، 2520 إطارًا.
- Doodle SVG + Motion Graphics + نص عربي كبير متصل.
- 9 مشاهد، لكل مشهد Composition مستقل في Remotion.
- خط Cairo للعناوين وTajawal للنصوص، من مشروع `fikra-01-influence` في نفس المستودع.
- أداة بصيرة/Arabic Carousel: خطة النصوص والمشاهد وفحصها. Remotion: الرسوم والحركة والتصدير. FFmpeg: الترميز وقياسات المراجعة.
- مؤثرات المشروع وخلفية نغمية أصلية. **لا تعليق صوتي في هذه النسخة**؛ ElevenLabs غير متصل بهذه الجلسة. لم يستبدل صوت نديم بصوت آخر.

## تشغيل

```sh
npm ci
python3 tools/make-bed.py
npm run studio
npm run typecheck
npm run render
```

عندما يلزم Chromium مخصص: اضبط `REMOTION_CHROME=/path/to/chromium` عند تشغيل أمر التصدير. في بيئة التنفيذ الحالية جرى استعمال Chromium الموجود؛ معالجة `networkInterfaces` تخص البيئة وتبقى خارج ملفات المشروع.

## تعديل مشهد

النصوص في `src/Scene.tsx`، الرسم المتحرك في `src/art.tsx`، توقيت المشاهد والمؤثرات في `src/Reel.tsx`. يمكن تصدير `Hook` أو `Plans` أو باقي التركيبات مستقلًا بدل إعادة تصدير الفيديو كله.

`timeline.json` يحفظ النصوص ومدد القراءة والحركة. `script.md` و`audio-request.json` يحفظان نص التعليق وصوت نديم `dlGxemPxFMTY7iXagmOj`. عند توفر ElevenLabs، ولّد من الملف نفسه، وافحص النص المرسل وبصمته ثم أعد التوقيت على التسجيل الفعلي؛ لا تدّعِ أن ملف الفيديو الحالي يحتوي هذا الصوت.

## المراجعة

`review/baseera-plan.json` — بصيرة: 9 مشاهد، 0 أخطاء، 0 تحذيرات. مدد خطة بصيرة الأولية 29.8 ثانية؛ جرى توسيع التوقيت في Remotion إلى 42 ثانية حتى تأخذ الرسوم والنصوص مجالًا للقراءة.

`review/copycheck.json` — 18 عنوانًا ونصًا مساعدًا مطابقًا للخط الزمني. فُحصت صور من بداية الريل وكل مشهد؛ صُحّح موضع «لا» في الختم. الفحص البصري للعينات لا يعادل اختبار أداء الحساب بعد النشر.

التقرير التقني ونتيجة `review-reel` يُحفظان بعد التصدير. لم يُنشر الريل على أي شبكة اجتماعية، ولا توجد ضمانات لعدد المشاهدات.

التصدير النهائي يضيف رفعًا مشتركًا للمزيج قدره 10dB بعد حفظ أصل Remotion، مع الحفاظ على سرعة الصوت وتوقيته، وتجهيز صورة H.264 بنطاق ألوان محدود متوافق. اختيار المستوى متناسب مع نسخة موسيقية بلا تعليق، وليس إعدادًا يُطبّق آليًا على صوت نديم مستقبلًا.
