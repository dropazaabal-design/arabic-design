# تأثير بقعة الضوء — ليش تحس إن الكل يراقبك؟

فيديو أفقي لـ«كتاب وبس» (إنستغرام وفيسبوك): 1920×1080، 60fps ثابت، 90 ث بالضبط (5400 إطار)، H.264/AAC — `out/spotlight.mp4`.

- **الفكرة البصرية:** مسرح ورقي مصغّر بعمق 2.5D (الجدار أبطأ، الستارة الأمامية أسرع)، وكشاف ضوء هو رمز لتقدير الشخص انتباه الآخرين، لا كاميرا. كرسي فارغ، فقاعة «صباح الخير» في الليل، ظلها يكبر على الجدار؛ دفتر، قميص، بطاقتان، أكواب، ميكروفون. بلا وجوه أو شخصيات بشرية.
- **العنوان الثابت:** «تحس إن الكل يراقبك؟» من الإطار 0 حتى 3 ث كاملة، والكشاف يتحرك تحته من أول إطار.
- **السكريبت المقفل:** `script.json` (14 جملة، والنصوص الظاهرة `onScreen`). الزوايا والاختيار: `plan/ideas.md`.
- **الصوت:** ElevenLabs `eleven_v4`، الصوت `dlGxemPxFMTY7iXagmOj`، هوية «نديم» **التجريبية**؛ الإعدادات كما أُرسلت للموصل في `voice.json`. عيّنة واحدة (`audio/sample-opening.mp3`) ثم تسجيل كامل واحد (`audio/elevenlabs-take-mHxF8zOhLWsXpIwtViSJ.mp3`، 77.5 ث). بلا تسريع أو تغيير طبقة: قصّ كل جملة على وقفاتها الحقيقية، وكسب ثابت واحد إلى −16 LUFS، والفرق إلى 90 ث وقفات صامتة عند تغيّر المشاهد. لم يُقيَّم بالسماع؛ Whisper يدلّ على فهم الكلمات فقط.
- **التوقيت:** `tools/voice60.py` يحاذي السكريبت مع كلمات Whisper، ويكتب `src/timeline.json` (بالثواني + fps 60 + 5400 إطار) و`src/captions.json` و`src/words.json`. كل حدث في `src/beats.ts` محسوب من زمن كلمة منطوقة بالثواني ثم `sec()`؛ لا عدّ إطارات يدوي. اهتزاز خط الـDoodle يتغيّر 8 مرات في الثانية مهما كان fps.
- **بصيرة:** خطة `canva_build_reel` (0 أخطاء، 0 تحذيرات) في `plan/` — أداة الريل عندها عمودية فقط، فاستُعملت لفحص النصوص وطول المشاهد لا للتصميم. تدقيق النصوص الموضوعة 12/12 (`tools/proof.mjs`)، وجُرّب بخطأ حرف مزروع فالتقطه.
- **التصدير والفحص:** رندر كامل، ثم أُعيد رندر أربعة مقاطع فقط (2400 إطار) بعد إصلاحات المراجعة، ولُصقت عند إطارات مفتاحية بلا إعادة ترميز؛ كل إطار من 5400 طابق مصدره (framemd5)، والصوت هو نفسه بتًّا ببت. الملف: H.264 High ‏1920×1080 ‏60/1 ثابت، 5400 إطار، 90.0 ث؛ AAC ‏48 ك.هـ ستيريو، −16 LUFS؛ لا إطارات سوداء. الكلمات المسموعة في الملف النهائي تطابق مواضعها في `src/words.json` (وسيط الفرق 0.00 ث).
- **المصدر:** Gilovich, Medvec & Savitsky (2000), *The spotlight effect in social judgment*, JPSP 78(2), 211–222. PMID 10707330.

```bash
npm install
python3 tools/voice60.py TAKE.wav WORDS.json --hold 4.5        # بعد تفريغ التسجيل بـ Whisper (كلمات بأزمنة)
REMOTION_CHROME=/path/to/chrome node tools/stills.mjs out stills 0 3s 45s   # لقطات للمراجعة
REMOTION_CHROME=/path/to/chrome npm run render
```
