# فكرة من كتاب — الحلقة ٢: «لماذا تقول نعم… وأنت تريد أن تقول لا؟»

حلقة يوتيوب أفقية لقناة «كتاب وبس» عن **إرضاء الآخرين** من كتاب «توقف عن إرضاء الآخرين» لباتريك كينغ (دار دوّن، ترجمة أسماء عرفة).
كتاب واحد، وفكرة واحدة، ومشكلة واحدة، وتطبيق واحد. ١٩٢٠×١٠٨٠ بـ٦٠ إطارًا في الثانية، والمدة تتبع التسجيل الحقيقي.

موقف واحد يتطوّر: رسالة غير عاجلة «ممكن تساعدني اليوم؟» والمساء محجوز لمشروعك. تكتب «لا أستطيع اليوم»، تمسحها، وترسل «حاضر». وفي الآخر تصل الرسالة نفسها، فتتوقّف، وتراجع وقتك، ثم تجيب.

## الحالة

**الحلقة مكتملة ومفحوصة تقنيًا، ولم تُنشر.** الفيديو على فرع `claude/vibrant-brown-rvpi3c` بطلب من صاحب القناة (رابط تحميل). التفاصيل والاستهلاك ونقطة الاستئناف في `checkpoint.json`.

| المرحلة | الحالة |
|---|---|
| البحث وبيانات الكتاب والألوان | تمّت (`research/notes.md`، `book.json`، `palette.json`) |
| الخطافات | خمسة خطافات مقارنة (`research/hooks.md`)، المختار #2 مع خاتمة #1 |
| السكربت | مقفل، 432 كلمة، 43 سطرًا (s01…s43)، بصمة النص في `speech/` |
| تخفيف حدّة الصوت | سلسلة EQ لطيف + de-esser خفيف، مقارنة قبل/بعد في `audio/softening-test/` |
| العيّنة | توليد واحد (174 رصيدًا)؛ اعتمدها صاحب القناة |
| التسجيل الكامل | توليد واحد (2469 رصيدًا = عدد الأحرف)، نصّه مبني آليًا من `script.json` ومطابق حرفيًا قبل الإرسال |
| المحاذاة | خط زمني مقيس: ‏222,98 ث = 13,379 إطارًا |
| الحلقة | `render/fikra-02.mp4` ‏(1920×1080، 60 ثابت، H.264 + AAC) |
| المراجعة | `review/technical.md`، `review/creative.md`، `review/reel-review/` (بصيرة) |
| النشر | الأغلفة والعنوان والوصف والكابشن جاهزة في `publish/`؛ لم يُرفع شيء إلى يوتيوب |
| لم يتم | استماع ومشاهدة بشرية كاملة، النشر (يحتاج إذنًا منفصلًا) |

**المدة أقصر من المطلوب:** الهدف 235–250 ث، والحلقة 223 ث. التسجيل جاء بنحو 125 كلمة في الدقيقة على 432 كلمة، ولم أملأ الفرق بصمت ولا بتبطيء. الوقفات المضافة مقصودة فقط (`timeline.json` → `addedBeats`).

## ملفات الحزمة

| الملف | ما فيه |
|---|---|
| `book.json` | الطبعة العربية (دار دوّن ٢٠٢١، ردمك 9789778062670) والأصل الإنجليزي. عدد الصفحات مختلف بين المصادر فلم يُستخدم. نصّ الكتاب لم يُقرأ، ولذلك لا اقتباس ولا رقم صفحة |
| `research/notes.md` | سجل البحث: كل ادّعاء ومستواه (من الكتاب / مصدر مستقل / مثال افتراضي)، وما تُرك عمدًا، وحدود الوصول |
| `research/hooks.md` | مقارنة الخطافات الخمسة |
| `episode-brief.json` | الصيغة والقواعد وسياسة الصوت والمزج |
| `script.md` / `script.json` | السكربت المقفل؛ كل سطر بمعرّفه ومشهده |
| `speech/` | نص التوليد كما أُرسل حرفيًا وبصماته (SHA-256) |
| `storyboard.json` | لكل مشهد: الغرض، والصورة، والحركة المربوطة بكلمة منطوقة، والنصوص الظاهرة حرفيًا، والألوان، وما طُبّق من ملاحظات الحلقة ١ |
| `timeline.json` | الأزمنة بالثواني، مقيسة من التسجيل الكامل (`tools/align.py`) |
| `palette.json` | ألوان الهوية الخمسة، والأزرق المائي والكرتوني من غلاف الطبعة العربية |
| `assets/SOURCES.md` | مصدر كل أصل وترخيصه |
| `audio/` | العيّنة، والتسجيل الكامل الأصلي، وسلسلة التخفيف، وكلمات Whisper، والمحاذاة |

| `checkpoint.json` | المراحل، والاستهلاك، والبصمات، ونقطة الاستئناف |
| `publish/` | غلاف يوتيوب (1280×720 و1920×1080) وغلاف الريل (1080×1920، آمن لشبكة 3:4)، والعنوان والوصف والفصول والكابشن (`publish.md`). مصدر الأغلفة `src/Cover.tsx` |

## التشغيل

```sh
npm install
npm run studio                       # المعاينة التفاعلية
npm run copycheck                    # النصوص الظاهرة = الستوري بورد حرفيًا
python3 tools/beatcheck.py           # كل حركة مربوطة بكلمة منطوقة فعلًا
npx tsc --noEmit -p .
# التصدير (يحتاج REMOTION_CHROME إلى متصفح Chromium headless):
npx remotion render src/index.ts Episode render/fikra-02.mp4 --audio-codec=aac --audio-bitrate=192k
python3 tools/verify.py render/fikra-02.mp4   # → review/technical.json
# إعادة المحاذاة من التسجيل نفسه (بلا أي توليد):
ffmpeg -i audio/take-full-fTjpf9jh2jXBhBso0v8B.mp3 -af "$(cat audio/softening-chain.txt)" -ar 48000 -ac 1 audio/take-full.wav
python tools/words.py audio/take-full.wav audio/take-full.whisper-words.json
python3 tools/align.py audio/take-full.wav audio/take-full.whisper-words.json --lead 0.5 --hold 4.0
python3 tools/srt.py                 # الترجمة render/captions.ar.srt من نص السكربت بترقيمه وأزمنة الكلمات المقيسة
```

لكل حركة كلمةٌ منطوقة تقع عليها (`wordAt` في `src/time.ts`). لا تُحرّك المشاهد يدويًا، ولا يُغيَّر الإيقاع أو طبقة الصوت. لتعديل مشهد واحد أعد تصدير تركيبته `Scene-scNN`.

## ما لم يُتحقَّق منه

- **لم يستمع إنسان إلى التسجيل الكامل ولم يشاهد الحلقة بزمنها.** Whisper يثبت وضوح الكلمات فقط؛ الكلمات التي تحتاج أذنًا وتوقيتها في `review/technical.md`.
- أثر سلسلة التخفيف مقيس بتوزيع الطاقة على الترددات، لا بالسماع.
- لم يُختبر العرض على يوتيوب ولا على هاتف.
- حقوق الاستخدام التجاري للصوت تتبع خطة حساب ElevenLabs.
- لا رفع إلى يوتيوب، ولا دفع إلى GitHub، دون إذن منفصل.
