# أغلفة السلسلة

غلاف سينمائي لكل جزء، بدقة 1080×1920، مرسوم بـRemotion وSVG، وبمجموعة الرسم والخطوط نفسها التي في الريلز.

## مكوّنات الغلاف

- **الخلفية والإضاءة:**
  - خشبة داكنة.
  - ضوء واحد من الأعلى، وحوله ضباب وغبار.
  - وهج أفقي (anamorphic flare) عند المصباح.
  - حبيبات فيلم وتعتيم للأطراف.
- **الرمز:** رمز الجزء في بقعة الضوء، بحافة مضيئة.
- **النصوص:**
  - عبارة الخطّاف في سطرين.
  - نطاق القوانين بالكلمات (من … إلى …)، لأن الشرطة بين الأرقام تنقلب في النص العربي.
  - حدّ أمان: كل النصوص بين y = 240 و1680، فيبقى الغلاف مقروءًا في قصّ 3:4 بشبكة الحساب.

## التشغيل

```sh
node tools/covers.mjs          # الأغلفة الستة → out/cover-0N.png و.jpg
node tools/covers.mjs 3        # غلاف جزء واحد
```

نسخة JPG من كل غلاف في `reels/qawanin-alquwwa-0N/export/qawanin-alquwwa-0N-cover.jpg`.
