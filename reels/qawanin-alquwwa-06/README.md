# «القوانين الثمانية والأربعون للقوة» — الجزء السادس (ريل 9:16)

ريل عربي عمودي مدته **2:50**، بدقة 1080×1920 و60 إطارًا في الثانية، مع H.264 وAAC. يعرض القوانين **27–32** من كتاب روبرت غرين،
ويتبع قواعد السلسلة في [`../qawanin-alquwwa/SERIES.md`](../qawanin-alquwwa/SERIES.md). الأدوات والخطوط ومجموعة الرسم منسوخة من الجزء الثاني.

- التنبيه العام منطوق ومعروض على الشاشة بنصه المعتمد.
- تنبيه خاص منطوق ومعروض في القوانين 27 و31 و32.
- المدة دون 3:00 لتبقى ضمن حد Reels وShorts، وتُحذف وسوم المُصيِّر من الملف عند التصدير.

## الصوت

صوت ElevenLabs بالمعرّف `dlGxemPxFMTY7iXagmOj` والنموذج `eleven_v4`؛ نسخة واحدة لكل مقطع، توفيرًا للرصيد. أوقات الكلمات من ElevenLabs Scribe في `timing/cNN.words.json`.

## التشغيل

```sh
python3 tools/timing.py                     # الصوت ← narration.wav + mix.wav (−16 LUFS) + src/timing.json
npx remotion studio src/index.ts            # المعاينة
SCALE=1 tools/render.sh out/reel-1080.mp4   # 1080×1920
python3 tools/srt.py                        # export/qawanin-alquwwa-06.ar.srt
```
