# فكرة من كتاب — الحلقة ١: «لماذا تقول «نعم» وأنت غير مقتنع؟»

حلقة يوتيوب أفقية لقناة «كتاب وبس» عن **مبدأ التباين** من كتاب «التأثير: علم نفس الإقناع» لروبرت سيالديني.
كتاب واحد، وفكرة واحدة، ومشكلة واحدة، وتطبيق واحد. ١٩٢٠×١٠٨٠ بـ٦٠ إطارًا في الثانية، والمدة تتبع التسجيل الحقيقي (الهدف نحو ٢٤٠ ثانية، والنطاق ١٨٠–٣٠٠).

## الحالة

**متوقّفة عند اعتماد العيّنة الصوتية.** الحالة كاملة، مع الخطوة التالية وأوامر الاستئناف، في `checkpoint.json`.

| المرحلة | الحالة |
|---|---|
| البحث وبيانات الكتاب والألوان | تمّت |
| السكربت | مقفل (٤٦٣ كلمة، ٣٧ سطرًا، ٨ مشاهد) |
| عيّنة الافتتاح (س٠١–س٠٣) | وُلّدت مرة واحدة (147 رصيدًا)، وتنتظر الاستماع والاعتماد |
| الستوري بورد والمشاهد الثمانية | مبنية على خط زمني مؤقّت، ومراجَعة بلقطات ثابتة |
| معاينة الافتتاح (١٦ ثانية) | `render/preview-opening.mp4`، بصوت العيّنة والمؤثرات |
| التسجيل الكامل، والمحاذاة، والتصدير النهائي، وreview-reel، والمراجعة الإبداعية، والتقارير | **لم تبدأ**: لا يُنفَق على التسجيل الكامل (تقديره 2668 رصيدًا) قبل اعتماد العيّنة |

## ملفات الحزمة

| الملف | ما فيه |
|---|---|
| `book.json` | الطبعة المعتمدة (العبيكان ٢٠١٠، ردمك 9789960547466) والطبعة الإنجليزية المستنتجة. نصّ الكتاب لم يُقرأ، ولذلك لا اقتباس ولا رقم صفحة |
| `research/notes.md` | الفكرة، وجدول نسبة كل ادّعاء إلى مستواه (المؤلف، التجربة المعروضة، المثال الافتراضي)، وما تُرك عمدًا (الإرساء، وتجربة «لأن»، وأثر الطُّعم) |
| `episode-brief.json` | الصيغة والقواعد وسياسة الصوت |
| `script.md` / `script.json` | السكربت المقفل؛ كل سطر بمعرّفه (s01…s37) ومشهده (sc01…sc08) |
| `storyboard.json` | لكل مشهد: الغرض، والصورة، والحركة المربوطة بكلمة منطوقة، والنصوص الظاهرة حرفيًا، والألوان |
| `timeline.json` | الأزمنة بالثواني. **مؤقّت** الآن، ويستبدله `tools/align.py` بأزمنة التسجيل الكامل المقيسة |
| `palette.json` | ألوان الهوية، ولونان من الغلاف |
| `assets/SOURCES.md` | مصدر كل أصل وترخيصه |
| `audio/` | العيّنة، وقياساتها (`sample-notes.json`)، وكلمات Whisper |
| `src/` | مشروع Remotion. كل مشهد مكوّن مستقل في `src/scenes/scNN.tsx`، وله تركيبة خاصة `Scene-scNN` لإعادة تصديره وحده |
| `review/` | فحص النصوص العربية؛ وتُضاف إليه التقارير التقنية والإبداعية بعد التصدير |
| `render/` | المعاينة الآن، والحلقة النهائية لاحقًا (`render/fikra-01.mp4`) والترجمة `captions.ar.srt` |
| `checkpoint.json` | المراحل، والاستهلاك، والبصمات، ونقطة الاستئناف |

## التشغيل

```sh
npm install
npm run studio                       # المعاينة التفاعلية
npm run copycheck                    # النصوص الظاهرة = الستوري بورد حرفيًا
npx tsc --noEmit -p .
# معاينة الافتتاح (يحتاج REMOTION_CHROME إلى متصفح Chromium headless):
npx remotion render src/index.ts Episode render/preview-opening.mp4 --frames=0-959 --audio-codec=aac --audio-bitrate=192k
# بعد التسجيل الكامل: الكلمات ← المحاذاة ← خط زمني مقيس
python tools/words.py audio/take-full.wav audio/take-full.whisper-words.json
python3 tools/align.py audio/take-full.wav audio/take-full.whisper-words.json --lead 0.5 --hold 4.0
npm run render                       # render/fikra-01.mp4
```

لكل حركة كلمةٌ منطوقة تقع عليها (`wordAt` في `src/time.ts`). لذلك يكفي تغيير التسجيل وإعادة المحاذاة؛ لا تُحرّك المشاهد يدويًا، ولا يُغيَّر الإيقاع أو طبقة الصوت.

## ما لم يُتحقَّق منه

- **لم يستمع إنسان إلى العيّنة بعد.** Whisper يثبت وضوح الكلمات فقط، لا طبيعية الأداء ولا اللكنة، وقد سمع «بمئتي» «دمائتي».
- مدة الحلقة النهائية غير معروفة قبل التسجيل الكامل. الخط الزمني المؤقّت (265.4 ث) تقدير بسرعة العيّنة.
- لا رفع إلى يوتيوب، ولا دفع إلى GitHub، دون إذن منفصل.
