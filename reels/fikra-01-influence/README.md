# فكرة من كتاب — الحلقة ١: «لماذا تقول «نعم» وأنت غير مقتنع؟»

حلقة يوتيوب أفقية لقناة «كتاب وبس» عن **مبدأ التباين** من كتاب «التأثير: علم نفس الإقناع» لروبرت سيالديني.
كتاب واحد، وفكرة واحدة، ومشكلة واحدة، وتطبيق واحد. ١٩٢٠×١٠٨٠ بـ٦٠ إطارًا في الثانية، والمدة تتبع التسجيل الحقيقي (الهدف نحو ٢٤٠ ثانية، والنطاق ١٨٠–٣٠٠).

## الحالة

**الحلقة مكتملة ومراجَعة تقنيًا وإبداعيًا، ولم تُنشر.** التفاصيل والاستهلاك ونقطة الاستئناف في `checkpoint.json`.

| المرحلة | الحالة |
|---|---|
| البحث وبيانات الكتاب والألوان | تمّت |
| عيّنة الافتتاح | 147 رصيدًا؛ اعتمدها صاحب القناة بالسماع |
| التسجيل الكامل | توليد واحد (2604 أرصدة، 228,6 ث). وُلّد من نص يختلف عن القفل الأول في 28 سطرًا؛ اعتمد صاحب القناة النص المسجَّل فصار هو السكربت المقفل (453 كلمة) |
| المحاذاة | خط زمني مقيس: ‏240,32 ث = 14,419 إطارًا بـ60 إطارًا/ث |
| الحلقة | `render/fikra-01.mp4` ‏(1920×1080، 60 ثابت، H.264 + AAC، ‏−16 LUFS) |
| المراجعة | `review/technical.md`، `review/creative.md`، `review/reel-review/` (بصيرة) |
| لم يتم | استماع ومشاهدة بشرية كاملة، صورة مصغّرة، النشر (يحتاج إذنًا منفصلًا) |

## ملفات الحزمة

| الملف | ما فيه |
|---|---|
| `book.json` | الطبعة المعتمدة (العبيكان ٢٠١٠، ردمك 9789960547466) والطبعة الإنجليزية المستنتجة. نصّ الكتاب لم يُقرأ، ولذلك لا اقتباس ولا رقم صفحة |
| `research/notes.md` | الفكرة، وجدول نسبة كل ادّعاء إلى مستواه (المؤلف، التجربة المعروضة، المثال الافتراضي)، وما تُرك عمدًا (الإرساء، وتجربة «لأن»، وأثر الطُّعم) |
| `episode-brief.json` | الصيغة والقواعد وسياسة الصوت |
| `script.md` / `script.json` | السكربت المقفل؛ كل سطر بمعرّفه (s01…s37) ومشهده (sc01…sc08) |
| `storyboard.json` | لكل مشهد: الغرض، والصورة، والحركة المربوطة بكلمة منطوقة، والنصوص الظاهرة حرفيًا، والألوان |
| `timeline.json` | الأزمنة بالثواني، مقيسة من التسجيل الكامل (`tools/align.py`) |
| `palette.json` | ألوان الهوية، ولونان من الغلاف |
| `assets/SOURCES.md` | مصدر كل أصل وترخيصه |
| `audio/` | العيّنة وقياساتها، والتسجيل الكامل الأصلي ونصّه المرسَل حرفيًا (`take-full.prompt.txt`)، وكلمات Whisper، والمحاذاة |
| `src/` | مشروع Remotion. كل مشهد مكوّن مستقل في `src/scenes/scNN.tsx`، وله تركيبة خاصة `Scene-scNN` لإعادة تصديره وحده |
| `review/` | فحص النصوص العربية، والتقرير التقني (`technical.md`/`technical.json`)، والمراجعة الإبداعية، ومخرجات reel-review |
| `render/` | الحلقة `fikra-01.mp4`، ومعاينة الافتتاح القديمة (بصوت العيّنة)، والترجمة `captions.ar.srt` |
| `checkpoint.json` | المراحل، والاستهلاك، والبصمات، ونقطة الاستئناف |

## التشغيل

```sh
npm install
npm run studio                       # المعاينة التفاعلية
npm run copycheck                    # النصوص الظاهرة = الستوري بورد حرفيًا
python3 tools/beatcheck.py           # كل حركة مربوطة بكلمة منطوقة فعلًا
npx tsc --noEmit -p .
# التصدير (يحتاج REMOTION_CHROME إلى متصفح Chromium headless):
npx remotion render src/index.ts Episode render/fikra-01.mp4 --audio-codec=aac --audio-bitrate=192k
python3 tools/verify.py render/fikra-01.mp4   # → review/technical.json
# إعادة المحاذاة من التسجيل نفسه (بلا أي توليد):
ffmpeg -i audio/take-full-fzjITWRAzial3C3ezAkg.mp3 -ar 48000 -ac 1 audio/take-full.wav
python tools/words.py audio/take-full.wav audio/take-full.whisper-words.json
python3 tools/align.py audio/take-full.wav audio/take-full.whisper-words.json --lead 0.5 --hold 4.0
```

لكل حركة كلمةٌ منطوقة تقع عليها (`wordAt` في `src/time.ts`). لا تُحرّك المشاهد يدويًا، ولا يُغيَّر الإيقاع أو طبقة الصوت. لتعديل مشهد واحد أعد تصدير تركيبته `Scene-scNN`.

## ما لم يُتحقَّق منه

- **لم يستمع إنسان إلى التسجيل الكامل ولم يشاهد الحلقة بزمنها.** Whisper يثبت وضوح الكلمات فقط؛ الكلمات التي تحتاج أذنًا وتوقيتها في `review/technical.md`.
- لم يُختبر العرض على يوتيوب ولا على هاتف.
- حقوق الاستخدام التجاري للصوت تتبع خطة حساب ElevenLabs.
- لا رفع إلى يوتيوب، ولا دفع إلى GitHub، دون إذن منفصل.
