# ليش تبدأ بحماس… وبعدين تتوقف؟

ريل «كتاب وبس» متحرّك (Doodle + Motion Graphics)، ١٠٨٠×١٩٢٠، ٣٠ إطارًا/ث، بعامية
عربية بيضاء وبصوت **«نديم — صوت كتاب وبس»** المحفوظ في `../voices/nadeem/`.

قلم رصاص يفتح دفترًا، فتتمدّد قائمة المهام وتزحم طريقه. يحاول الرياضة والقراءة
والشغل معًا، فيرتطم بجدار منها ويتوقف. ثم يصغّر البداية إلى فعل واحد واضح، ويجهّز
أدواته، ويكمل حتى بعد يوم فائت.

الملف: `out/start-small.mp4` — ٤٤٫٩٧ ث (١٣٤٩ إطارًا)، H.264 ‏(yuv420p) + AAC.

## المسار كما جرى فعلًا

| المرحلة | الأداة | ما حدث |
|---|---|---|
| الصوت | **Chatterbox Multilingual** (Resemble AI، محلي على CPU) | اختبار ثلاث عيّنات للنص نفسه (A دافئ، B حواري، C حيوي) → اختار صاحب الحساب **A** → حُفظت الهوية كاملة في `../voices/nadeem/profile.json` (المرجع ببصمته، ومراجعة النموذج وبصمات ملفاته، والإعدادات، وتوجيه الأداء، وعيّنة مرجعية). بصيرة لا تملك أداة صوت |
| الهوية | **بصيرة** `studio brand` | نسخة `kitabwbs-motion` (`brand.json`): أزرق «كتاب وبس» وأحمره وأخضره وخطوطه، مع ألوان إضافية كما أُذن (كهرماني، مرجاني، بنفسجي، فيروزي) |
| التخطيط | **بصيرة** `canva_build_reel` | خطة المشاهد نجحت بلا أخطاء (`plan/baseera-build-reel.json`): الخطّاف أولًا، فكرة لكل مشهد، نص قصير |
| التدقيق | **بصيرة** `studio check --source` | كل نص يرسمه `src/Reel.tsx` قورن حرفًا بحرف بالنص المعتمد في `script.json` → ‏١٤/١٤، ٠ أخطاء؛ وخطأ مزروع («صفحتان») التُقط (`plan/`) |
| المكتبة | **بصيرة** `studio asset add` | ١١ رسمًا مستقلًا بلا نص (`assets/library/`: القلم بثلاث حالات، قائمة المهام، تقويم اليوم الفائت، المؤقّت، حجر الطريق، أيقونات) سُجّلت بوسم `kitabwbs-motion` |
| الحركة | **Remotion** 4.0.534 | رسوم SVG مرسومة بالكود، وكل حركة مربوطة بإطار من مُدد الصوت المقيسة (`src/beats.ts` ← `src/timeline.json`) |
| الفحص والتصدير | **FFmpeg / ffprobe**، **faster-whisper** | تطبيع الصوت، قياس المُدد والملف، فحص النطق آليًا |
| Canva | **لم يُستدعَ** | الموصل لا يحمل حركة ولا صوتًا ولا توقيتًا |

## الصوت

- الاتجاه A (exaggeration 0.35، cfg_weight 0.55، temperature 0.7)، بذرة ٧، ثم سرعة ١٫١
  بلا تغيير الطبقة وسقف ٠٫٤ ث للصمت داخل السطر، و−16 LUFS لكل مقطع.
- فحص Whisper لكل سطر؛ خمسة أسطر أُعيدت: ‏s1 «تقرر»، s2 «رياضة/شغل»، s5، s7 «ضخمة/اختار»،
  s12 «شيء». بعد الإعادة: ‏s1 وs2 وs5 وs12 مطابقة ١٫٠، وs7 ‏٠٫٨٦ (الكلمتان سليمتان).
- **تعديل شفهي واحد**: النموذج لم ينطق «تصغّرها» سليمة في ست محاولات، فصار المنطوق
  «جرّب تخلّيها أصغر» (١٫٠)، وبقي العنوان على الشاشة «صغّرها».
- ملاحظات النطق محفوظة في الهوية (`pronunciation`) لتُستعمل في الفيديوهات القادمة.
- **لم أستمع**: الفحص آلي. اختيار الصوت كان بسمعك أنت.

## المشاهد والتوقيت

| المشهد | الزمن | التعليق | ما يحدث | النص على الشاشة |
|---|---|---|---|---|
| 1 | 0.0–4.5 ث | تعرف أول يوم، لما تقرر تغيّر حياتك كلها؟ | القلم يفتح غلاف الدفتر (يمينًا) ويؤشّر بسرعة، والقائمة تتمدّد صفًّا بعد صف | تبدأ بحماس… وبعدين تتوقف؟ |
| 2 | 4.5–10.0 ث | رياضة، وقراءة، وشغل… وكل هذا من بكرة. | ثلاث بطاقات تخرج من القائمة؛ ورقة تقويم «بكرة» تسقط | رياضة · قراءة · شغل · كل هذا… من بكرة |
| 3 | 10.0–15.9 ث | وبعد كم يوم… تتوقف. ممكن البداية نفسها كانت أكبر من وقتك وطاقتك. | البطاقات تصير جدارًا يسدّ الطريق؛ القلم يدفع وينحني، الأيام تمرّ، فيتوقف؛ الجدار يعلو، المؤقّت يدور والبطارية تفرغ | البداية أكبر من طاقتك |
| 4 | 15.9–25.1 ث | جرّب تخلّيها أصغر. بدل ساعة قراءة، ابدأ بصفحتين. وبدل خطة رياضية ضخمة، اختار تمرين بسيط. | القلم ينقر الجدار فينهار إلى بطاقتين صغيرتين؛ ينقر الكتاب السميك فيصير صفحتين، وينقر الخطة الضخمة فتصير حذاءً واحدًا | صغّرها · صفحتين · تمرين بسيط |
| 5 | 25.1–28.6 ث | حدّد له وقت، وجهّز اللي تحتاجه قبلها. | مؤقّت يُضبط؛ الكتاب والحذاء على رف؛ القلم يضع الفاصل في الكتاب ويدفع الحذاء إلى مكانه | وقت محدد… وأدوات جاهزة |
| 6 | 28.6–32.0 ث | وإذا فاتك يوم، ارجع في اليوم اللي بعده. | تقويم من اليمين: ثلاثة أيام مؤشّرة، يوم فارغ بخط متقطّع، ثم يعود القلم ويؤشّر اليوم التالي | فاتك يوم؟ ارجع بكرة |
| 7 | 32.0–35.8 ث | بعد ما يصير أسهل عليك، زِد خطوة. | العلامات تصير حجارة ترتفع درجًا؛ القلم يصعد، وتُضاف درجة جديدة فيقف عليها | سهلت؟ زِد خطوة |
| 8 | 35.8–45.0 ث | مو لازم تعمل كل شيء اليوم. خلّ عندك شيء واضح… تقدر ترجع له بكرة. | الدرج يستوي طريقًا؛ بطاقة واحدة واضحة؛ القلم يمشي إليها ويؤشّرها | بداية تقدر تكرّرها · كتاب وبس |

بلا وجوه بشرية (للقلم عينان مرسومتان فقط)، بلا كلمات إنجليزية في التصميم، بلا موسيقى:
مؤثرات خفيفة على الأفعال فقط (تقليب ورق، علامة، نقرة، ارتطام).

## التحقّق

| البند | النتيجة |
|---|---|
| الملف | H.264 High، yuv420p، ١٠٨٠×١٩٢٠، ٣٠ إطارًا/ث؛ AAC‏ ٤٨ ك.هـ ستيريو؛ ١٤٫٢ م.ب |
| المدّة | ١٣٤٩ إطارًا = ٤٤٫٩٧ ث، مطابقة لخطّة التوقيت؛ داخل الهدف ٣٥–٤٥ ث |
| الصوت في الملف | −16.4 LUFS، ذروة −3.0 dBFS؛ لا صمت فوق ثانية إلا وقفة الختام (١٫٦ ث) |
| الخطّاف | ظاهر كاملًا من الإطار ٠ وثابت حتى ٤٫٨ ث |
| تدقيق بصيرة | ١٤/١٤ نصًّا مطابقًا حرفًا بحرف، ٠ أخطاء؛ والخطأ المزروع التُقط |
| خطة بصيرة | ٠ أخطاء، ٠ تحذيرات بهوية `kitabwbs-motion` |
| النطق (Whisper، الملفات النهائية) | متوسّط ٠٫٩٣؛ تسعة أسطر ١٫٠. الأدنى s8 ‏(٠٫٦٢) وs10 ‏(٠٫٧٧) فروق حدود كلمات فقط («لتحتاجه»، «بعدما») |
| المراجعة البصرية | لقطات لكل مشهد ثم إطار كل ٢٫٢٥ ث من الملف نفسه؛ أُصلح منها: خطأ إطارات المشهد ٦+، بطاقة تظهر قبل أوانها، جدار بلا بطاقات «شغل»، فراغ بعد «صغّرها»، القلم الساكن في المشهد ٤، القلم المخترق للرف |
| ما لم يُفحص | الاستماع البشري للصوت النهائي؛ ولا بيانات مشاهدة — الحكم التحريري حكمي |

## إعادة الإنتاج

```bash
npm install
# الصوت: ../voices/nadeem/README.md (speak.py ثم tools/normalize-voice.sh IN OUT 1.1 0.4)
node tools/timeline.mjs                     # المُدد المقيسة → src/timeline.json
REMOTION_CHROME=/path/to/chrome npm run render
# تدقيق بصيرة للنصوص الموضوعة:
BASEERA_HOME=… node tools/proof.mjs out/proof
# الرسوم المستقلة:
npx esbuild tools/export-assets.tsx --bundle --platform=node --outfile=out/export.cjs && node out/export.cjs
```
