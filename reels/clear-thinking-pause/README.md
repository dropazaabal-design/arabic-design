# لا ترسلها وأنت غاضب — ريل «كتاب وبس»

ريل عربي ٩:١٦ مستوحى من كتاب **«التفكير الواضح»** لشين باريش، عن فكرة واحدة: **الوقفة بين الحدث ورد الفعل تتيح فرصة للتفكير قبل التصرف.**
الزاوية: رسالة تكتبها وأنت غاضب، ثم تراجعها بعد أن تهدأ. هاتف واحد يتحرّك عبر الريل كله: موقف، ثم تطوّر، ثم حل.

## التسليم

الحالة: **مكتمل ومصدَّر ومقيس** — 49٫5 ث، ‏−14٫3 LUFS، Whisper سمع 90/90 كلمة من صوت الملف النهائي. لم يستمع إليه إنسان بعد (`review/technical.md`).

| الملف | ما فيه |
|---|---|
| `render/la-tursilha.mp4` | الريل النهائي: 1080×1920، 30 إطارًا/ث، H.264 ‏yuv420p + AAC |
| `render/cover-opening.png` | صورة معاينة من الافتتاح (الإطار 36، 1٫2 ث: الهوك كبيرًا وحلقة الإرسال تتوقف) |
| `render/captions.ar.srt` | الترجمة كاملة بتوقيتها المقيس (يشمل جملة الهوك) |
| `publish/caption.txt` | عنوان فيسبوك والكابشن |
| `review/technical.md` | ملخص التحقق: ما اختُبر وما لم يُختبر (والأرقام الخام في `technical.json`) |
| `review/contact-sheet.jpg` | إطار كل ثانية من الملف المصدَّر |

## المصدر ودقّة الاستلهام

- الكتاب: «التفكير الواضح» (Clear Thinking) لشين باريش. أساس الفكرة من مقتطف الناشر: <https://www.penguinrandomhouseretail.com/book/?isbn=9780593086117>.
- الحلقة الملهمة: «ابدأ بتحسين أفكارك لتحسن حياتك — كتاب التفكير الواضح — الجزء الأول» (دوباميكافين) <https://www.youtube.com/watch?v=zbjjngEcU_M>. لم يتوفّر تفريغها؛ لا شيء في الريل منسوب إليها، ولا صوت أو لقطة منها.
- المحادثة والموقف وعبارة «سأردّ عندما أهدأ» من إعدادنا، تطبيق مقترح لا اقتباس. لا أسماء أو رسائل حقيقية. الرد الهادئ معلَّم على الشاشة بـ«مثال».
- بطاقة الكتاب في المشهد الرابع قصاصة ورقية من تصميمنا، لا الغلاف.

## كيف صُنع

| المرحلة | الأداة | ما جرى |
|---|---|---|
| النص | — | النص الصوتي المقفل محفوظ حرفيًا في `script.json`، ومعه تقسيم الترجمة. مدخل الصوت `audio/take.prompt.txt` = النص نفسه، والإضافة الوحيدة شدّة على «المسوَّدات» |
| الصوت | ElevenLabs ‏`eleven_v4` | الصوت `dlGxemPxFMTY7iXagmOj`، المعتمد سابقًا بسمع صاحب القناة لريلات «كتاب وبس» (محفوظ في سجلّ المشروع). توليد واحد بأربع نسخ (2004 أرصدة)، اختيرت النسخة `XJcITRwV6AaOxD9u2N2x` لأن Whisper ‏large-v3 سمع كل كلماتها مطابقة للنص |
| المحاذاة | faster-whisper + FFmpeg | `tools/words.py` ثم `tools/align.py`: أزمنة الكلمات مثبّتة على الوقفات المقيسة؛ وقفتان أُطيلتا داخل صمت طبيعي (0٫6 ث قبل «ارجع»، 0٫4 ث قبل «اكتب لنفسك قاعدة»). لا تسريع ولا تبطيء ولا تغيير طبقة |
| الحركة | Remotion 4.0.534 | كل حركة مربوطة بكلمة منطوقة (`at()` في `src/time.ts`). الخطوط Cairo وTajawal محمّلة قبل أول إطار، والقياس بعد تحميلها |
| الأصول | رسوم متجهة بالكود | الهاتف، المحادثة، القصاصات، النافذة وكوب الماء، الرموز. لا صور مولّدة، ولا نص عربي داخل صورة |
| المؤثرات | ملفات FFmpeg من تاريخ المستودع | سبعة مؤثرات خفيفة جدًا (نقرة، فرقعة، تقليب ورق، حفيف)، بلا موسيقى ولا صوت إشعار |
| ما أُعيد استعماله | تاريخ المستودع | لا مكوّن ArabicText في المستودع الحالي. أُعيد استعمال محمّل الخطوط (`src/fonts.ts`) وملفات Cairo/Tajawal، وأدوات المحاذاة والتحقق، والمؤثرات من مشروعي `fikra-01-influence` و`crab-mentality` في تاريخ git، معدّلة للريل الرأسي. أدوات بصيرة (`studio.mjs`) مخصّصة للكاروسيل وCanva، فلم تُستعمل للحركة؛ ومدقّق الكابشن في `lib/copy.js` فحص الكابشن والعنوان والنص: صفر ملاحظات |

## ملفات المشروع

```
script.json          النص المقفل، والكتاب، ومصادر الاستلهام، وتقسيم الترجمة
storyboard.json      المشاهد السبعة: الصورة، والحركة، والكلمة التي تقع عليها، والنصوص الظاهرة حرفيًا
timeline.json        الأزمنة المقيسة (بالثواني) والمدة بالإطارات
audio/               النسخ الأربع للتسجيل، وكلمات Whisper، والمحاذاة
public/voice/        مسار الصوت النهائي (−14 LUFS)
src/                 مشروع Remotion: Reel.tsx (التركيب والكاميرا والهوك)، Phone.tsx (الهاتف وقصّته)، art.tsx (الرسوم)، text.tsx (الترجمة والقياس)
tools/               align.py، words.py، verify.py، copycheck.mjs، fontcheck.py، stills.mjs
```

## التشغيل

```sh
npm install
npm run studio                                   # المعاينة والتعديل
node tools/copycheck.mjs                         # النصوص الظاهرة = الستوري بورد، والترجمة = النص المقفل
python tools/fontcheck.py                        # كل حرف ظاهر موجود في خطّه
npx tsc --noEmit -p .
# صور مراجعة (مع خطوط المناطق الآمنة): REMOTION_CHROME=… node tools/stills.mjs OUT --guides 0 9 20.6
REMOTION_CHROME=… npx remotion render src/index.ts Reel render/la-tursilha.mp4 --audio-codec=aac --audio-bitrate=192k
python3 tools/verify.py render/la-tursilha.mp4   # → review/technical.json
# إعادة المحاذاة من التسجيل نفسه (بلا أي توليد جديد):
python tools/words.py audio/take-XJcITRwV6AaOxD9u2N2x.mp3 audio/take-XJcITRwV6AaOxD9u2N2x.whisper-large.json large-v3
python3 tools/align.py audio/take-XJcITRwV6AaOxD9u2N2x.mp3 audio/take-XJcITRwV6AaOxD9u2N2x.whisper-large.json
```

لتعديل نص على الشاشة: `src/copy.ts` ثم `storyboard.json`، ثم `copycheck`. لا يُغيَّر النص الصوتي دون توليد جديد ومحاذاة جديدة.
