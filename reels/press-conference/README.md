# «حياتك ليست مؤتمرًا صحفيًا»

ريل عربي أصلي بمقاس 1080×1920، **60 إطارًا/ث**، ومدته 86.04 ث، من حزمة `KITABWBS_PRESS_CONFERENCE_CLAUDE-1.md` (الخيار 1).

**القصة:** روبوت صغير بلا وجه يبني جسرًا فوق فجوة في طاولة ورشة.
1. **التعثّر:** كلما تعثّر ترك الأدوات وصعد منصة صغيرة مليئة بالميكروفونات ليشرح. الجسر بقي معوجًّا والساعة تمضي.
2. **الكشف:** يتعطّل الميكروفون، فيكتشف أن أغلب الكراسي فارغة، وأن بعض الأصوات كانت في رأسه.
3. **العودة:** يرجع إلى الطاولة: يجرّب، ويخطئ، ويعدّل، ويطلب يدًا ثانية. الجسر يكتمل بالعمل والتعلّم وقبول المساعدة، لا بالسكوت.
4. **الخاتمة:** يعتذر حين يلزم، ويعمل مع غيره، ويختار الطاولة لا المنصة. لا تصفيق في النهاية.

## التشغيل

```sh
(cd ../motion && npm ci) && npm ci
npm run voice        # التوقيت والترجمة من التسجيل، ثم ضغط وتحديد ذروات الأسطر
npm run sfx          # المؤثرات الأصلية
npm run storyboard   # storyboard.json من storyboard.src.json
npm run mix          # الصوت وحده لضبط MIX_GAIN
npm run render       # التصيير النهائي + إعادة الترميز + output/render-time.json
npm run cover        # الغلافان 1080×1920 و1080×1350
npm run check        # ترتيب الإطارات، وتطابق 30/60، وفك MP4
npm run gates        # بوابات الجودة على الملف النهائي
python3 ../tools/patch_render.py . A-B   # إصلاح صورة في مدى إطارات دون تصيير كامل (الصوت كما هو)
```

**قبل النشر:** يلزم سماع بشري للأداء والنطق. التفريغ المستقل يثبت الكلمات وترتيبها فقط.
