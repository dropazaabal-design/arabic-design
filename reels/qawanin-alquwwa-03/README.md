# «القوانين الثمانية والأربعون للقوة» — الجزء الثالث (ريل 9:16)

ريل عربي عمودي مدته **2:56**، بدقة 1080×1920 و60 إطارًا في الثانية، مع H.264 وAAC. يعرض القوانين **11–15** من كتاب روبرت غرين،
ويتبع قواعد السلسلة في [`../qawanin-alquwwa/SERIES.md`](../qawanin-alquwwa/SERIES.md). الأدوات والخطوط ومجموعة الرسم منسوخة من الجزء الثاني.

- التنبيه العام منطوق ومعروض على الشاشة بنصه المعتمد.
- تنبيه خاص منطوق ومعروض في القوانين 11 و12 و14 و15.
- المدة دون 3:00 لتبقى ضمن حد Reels وShorts، وتُحذف وسوم المُصيِّر من الملف عند التصدير.

## البنية

| المقطع | المحتوى |
|---|---|
| c00 | الخطّاف والتعريف بالجزء |
| c01 | التنبيه المنطوق حرفيًا (صوته من الجزء الثاني) |
| c02 | القانون الحادي عشر: اجعل الناس معتمدين عليك |
| c03 | القانون الثاني عشر: استعمل الصدق والكرم الانتقائيين لتجريد ضحيتك من سلاحها |
| c04 | القانون الثالث عشر: عند طلب المساعدة خاطب المصلحة، لا الرحمة ولا الامتنان |
| c05 | القانون الرابع عشر: تظاهر بالصداقة واعمل جاسوسًا |
| c06 | القانون الخامس عشر: اسحق عدوك تمامًا |
| c07 | الخلاصة والتشويق وسؤال التعليقات |

## الصوت

صوت ElevenLabs بالمعرّف `dlGxemPxFMTY7iXagmOj` والنموذج `eleven_v4`؛ نسختان لكل مقطع، واستُعملت الأولى إلا حيث نفد الرصيد فاستُعملت الثانية. أوقات الكلمات من ElevenLabs Scribe في `timing/cNN.words.json`.

## التشغيل

```sh
python3 tools/timing.py                     # الصوت ← narration.wav + mix.wav (−16 LUFS) + src/timing.json
npx remotion studio src/index.ts            # المعاينة
SCALE=1 tools/render.sh out/reel-1080.mp4   # 1080×1920
python3 tools/srt.py                        # export/qawanin-alquwwa-03.ar.srt
```
