# «آداب المجلس» — Creative Reel 1 (cr1)

ريل عربي بمقاس 1080×1920، **60 إطارًا/ث**، ومدته 88.6 ث. أُعدّ من حزمة `ADAB_AL_MAJLIS_MASTER.md` بترتيبها: الأدب بالفعل أولًا، ثم دليله.

| # | الأدب | الدليل |
|---|---|---|
| 1 | لا تفرّق بين اثنين إلا بإذنهما | أبو داود 4845 |
| 2 | احفظ مكان من قام لحاجة | مسلم 2179 |
| 3 | اترك مساحة لمن بجانبك | أقوال في كتب الأدب، بلا مقدار ملزم |
| 4 | افسح للداخل | المجادلة 11 |
| 5 | من أدب المجلس أن يفسح الجالس | تفسير السعدي |
| 6 | الجزاء من جنس العمل | تفسير السعدي |

**الأسلوب البصري:**
- **الشخصيات:** جالسون رمزيون بلا ملامح وجه في مجلس أرضي، والمتعلم بالأزرق.
- **الألوان:** الأحمر للخطأ والأخضر للصواب، بلا أصفر ولا برتقالي ولا ذهبي.
- **الصوت:** بلا موسيقى.

| الملف | ما هو |
|---|---|
| `output/final_reel.mp4` | الفيديو النهائي |
| `publish/cover-1080x1920.jpg` | الغلاف (Cover بالإطار 2172) |
| `output/captions.ar.srt` | الترجمة |
| `publish/publish.md` | العناوين والكابشنات: يوتيوب وفيسبوك وإنستغرام |
| `output/qa_report.md` | تقرير الجودة التقني والبصري |
| `script.md` | المصادر وما قُرئ منها، والنص المقفول، والصوت |
| `storyboard.md` / `storyboard.src.json` | 7 لقطات مثبتة على الكلمات |
| `src/scene/shots.tsx` | اللقطات |
| `src/scene/kit.tsx` | الشخصية، والمجلس، والبطاقات، والعلامات |
| `tools/sfx.py` | المؤثرات الأصلية |
| `assets/asset_manifest.json` | الأصول ومصادرها وحقوقها |

## التشغيل

```sh
(cd ../motion && npm ci) && npm ci
npm run voice        # الصوت والتوقيت والترجمة من التسجيل (reels/tools/voice_timeline.py)
npm run sfx          # المؤثرات الأصلية
npm run storyboard   # storyboard.json من storyboard.src.json
npm run mix          # الصوت وحده لضبط MIX_GAIN (ثوانٍ)
npm run render       # التصيير النهائي + إعادة الترميز + output/render-time.json
npm run cover
npm run check        # ترتيب الإطارات، وتطابق 30/60، وفك MP4
npm run gates        # بوابات الجودة على الملف النهائي
python3 ../tools/patch_render.py . A-B   # إصلاح صورة في مدى إطارات دون تصيير كامل (الصوت كما هو)
```

**قبل النشر:** يلزم أن يسمع إنسان الآية والحديثين ويتأكد من النطق. التفريغ الآلي يثبت الكلمات وترتيبها فقط، لا الحركات ولا الإعراب (`script.md`).
