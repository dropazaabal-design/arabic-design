# `lib/lexicon/ar.txt.gz`

قائمة كلمات عربية بتردّداتها، تُستعمل لتصحيح مسافة تحرير واحدة في
`lib/spelling.js`.

## المصدر والرخصة

**[hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords)** —
`content/2018/ar/ar_full.txt`، مشتقّة من متن OpenSubtitles.
**رخصة MIT**، © 2016 Hermit Dave.

## كيف بُنيت

من ٢٫٣٨ مليون صورة سطحية عربية في المصدر:

1. حُذفت كل سلسلة فيها محرف غير عربي، وكل كلمة أقلّ من حرفين.
2. نُزعت الحركات والتطويل من الصورة السطحية.
3. جُمعت الصور تحت **مفتاح مطبَّع**: `أ إ آ ٱ ← ا`، `ى ← ي`، `ة ← ه`.
4. لكل مفتاح: مجموع التردّدات، والصورة السطحية الأعلى تردّدًا (هي المرشَّح
   الذي يُقترح، فالاقتراح يجب أن يكون مكتوبًا كتابة صحيحة لا مطبَّعًا).
5. أُسقط كل مفتاح تردّده دون **٢٠**.

النتيجة: **١٧٠٬٤١٢** مدخلة، ٢٫٦٤ ميغابايت خامًا، **٠٫٨٥ ميغابايت** مضغوطة.

الصيغة: سطر لكل مفتاح، `الصورة التردّد`، مرتّبة تنازليًا بالتردّد. المفتاح
يُشتقّ بالتطبيع عند التحميل، فلا يُخزَّن.

## لماذا عتبة ٢٠، ولماذا لا تكفي وحدها

المتن يحوي أخطاءً مطبعية بتردّدات منخفضة: `أستيقط` موجودة فيه ٤٤ مرة.
لذلك تُستعمل عتبتان مختلفتان في `spelling.js`:

- **٥٠** لاعتبار الكلمة معروفة فتُترك. `أستيقط` (٤٤) تقع تحتها فتُفحص.
- **٢٠** لاعتبار الكلمة مرشَّحًا صالحًا. `تتقنه` (٣٦) تقع فوقها فتصلح اقتراحًا.

## حدّ المعرفة

المتن ترجمات أفلام: عامّي في مواضع، وفيه أخطاء. لذلك **وجود الكلمة فيه ليس
شهادة صحّة**، وشروط التطبيق الآلي في `spelling.js` لا تعتمد على الوجود وحده.
راجع «شرط التطبيق الآلي» في `REFERENCE.md`.

## إعادة البناء

```bash
curl -sS -o ar_full.txt \
  https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/ar/ar_full.txt
node tools/build-lexicon.js ar_full.txt lib/lexicon/ar.txt.gz
```
