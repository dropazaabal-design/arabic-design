# بصيرة — Narrative Director Contract v1

هذه المرحلة تفصل قرار المخرج الإبداعي عن الكود. يفهم Remotion حركات TSX، لكن
**لا يفهم الرسالة النفسية أو معنى القصة وحده**. على محرّر أو وكيل ذكي إنتاج
`character-storyboard.json` مع ربط كل قرار بصري بكلمة من المحاذاة الصوتية.

## المسار
`النص + الكلمات المقيسة` → `اقتراح Storyboard` → `prepareStoryboard()`
→ `directStory()` → `compileMotionPlan()` → `CharacterActor` → Remotion/FFmpeg.

- `src/storyboard-contract.ts`: يتحقق من مخطط JSON وهو مدخل غير موثوق.
- `demo/character-storyboard.json`: مثال عربي مرتبط بملف Whisper الموجود.
- `demo/CharacterStory.tsx`: صار يستهلك ملف Storyboard لتحديد الإيماءات
  وتسلسل الكاميرا والنص القصير الظاهر.
- `tests/storyboard.test.mjs`: اختبارات تمنع التخمين عند غياب كلمة أو اختلافها،
  أو استخدام ممثل غير موجود، أو تراكب لقطات، أو توقيت خارج مدة الصوت.
- **المستوى الإبداعي لم يُقَس**: أي نتيجة نموذج ينبغي اختبارها بصريًا والاستماع إليها.

## صيغة الإدخال
```json
{
  "version": 1,
  "language": "ar",
  "description": "الحدث وما يتغير في القصة",
  "actors": [{"id": "hero", "role": "الدور الدرامي للشخصية"}],
  "cues": [{
    "id": "pause-1",
    "wordId": "s01:3",
    "expectedWord": "غاضب",
    "actorId": "hero",
    "direction": "hesitate",
    "durationMs": 750,
    "visualReason": "تجسيد الصراع قبل الرد"
  }],
  "shots": [{
    "id": "opening",
    "fromWordId": "s01:0",
    "toWordId": "s01:3",
    "camera": "wide",
    "focusActorId": "hero",
    "visualReason": "تأسيس المساحة وعلاقة الشخصية بالفعل"
  }]
}
```

الحركات المتاحة حاليًا:
`enter`, `notice`, `hesitate`, `explain`, `emphasize`, `decide`, `exit`.
زوايا الكاميرا: `wide`, `medium`, `close`.

`wordId` و`expectedWord` **ليسا نصًا تخمينيًا**: يجب نسخهما بدقة من
`src/words.json`، ومطابقتهما تحقق إلزامي. الأفعال ذات مدة محددة وُضعت
عمدًا كي لا ينتج عن كلمة واحدة تحريك طويل لا يراعي الصوت.

## تعليمات الوكيل الإبداعي (Claude Code / Codex أو نموذج آخر)
1. اقرأ السكربت والكلمات المقيسة قبل إنشاء أي JSON.
2. اكتب الحدث البصري كسبب ونتيجة؛ لا تجعل كل كلمة حركة مستقلة.
3. أنشئ الإيقاع بانتقال في وظيفة اللقطة، لا بتغيير الخلفية فقط.
4. اربط الفعل المرئي بالكلمة المناسبة، ولا تتجاوز مدة الصوت.
5. الشخصيات البشرية الكرتونية مسموحة حين تخدم الفكرة (طقم `src/cartoon`)، والصور البشرية الواقعية ممنوعة، ولا نص إنجليزي على الشاشة.
6. اكتب `visualReason` محددًا: *لماذا هذه الحركة هنا؟* لا عبارات عامة.
7. لا تغيّر هوية الشخصيات بلا سبب. رَاعِ اتساق المكان وتوازن اللقطات.
8. لا تدرج مفتاح API، ولا تولّد صوتًا جديدًا عند اختبار مقطع صوت مقفل.
9. أرجع **JSON صالحًا** بنفس العقد؛ لا تضع JSX أو HTML داخله.
10. اجعل `prepareStoryboard()` و`compileMotionPlan()` يرفضان أي تعارض
    قبل إنشاء الفيديو، ثم راجع ملف MP4 الناتج بصريًا.

**الحدود:** هذا عقد يستقبل المقترح، وليس خدمة AI تعمل ذاتيًا. ربط مزود
نموذج فعلي لتوليد JSON آليًا لم يُنفذ بعد، ولا توجد مقارنة بصرية مع Claude.

## التشغيل
```bash
cd motion-core
npm install
npm test
npm run typecheck
npm run story:render:full
```

الاختبار CI يلتقط العطب التقني فقط؛ النتيجة المنشورة تحتاج تقييمًا بصريًا
للنص العربي، وإيقاع المشاهد، وتجانس الجسد مع الأداء الصوتي.
