# صفحة «بكج افهم نفسك» على kitabwbs.com

صفحة بيع جديدة تحل محل الصفحة الحالية، بهوية إعلان البكج: كحلي `#071525`، وأزرق `#2E7BC5`، وأخضر زمردي `#10B981`، وأبيض `#F8FAFC`، وخطّا Tajawal وCairo.

## الرفع
ارفع إلى جذر الموقع:
- `index.html`
- مجلد `assets/` كاملًا: أغلفة الملفات الستة، وصفحتان من «قوة العادات»، وصورة المشاركة `og-image.jpg`.

**احتفظت من الصفحة السابقة بما يلي:**
- رابط الدفع على Buy Me a Coffee.
- تحليلات Google بالمعرّف نفسه، وأضفت حدثَي `begin_checkout` و`select_track`.
- الروابط `/legal/privacy-policy` و`/legal/terms-of-use`.
- البيانات المنظمة (Product وFAQ) والعنوان الأساسي.

## السعر
السعر واحد وثابت: **99 ريالًا** (26.40 دولارًا في صفحة الدفع). لا خصم ولا عدّ تنازلي ولا «سعر إطلاق».

- **لتغييره كاملًا:** عدّل `PRICE` و`USD` في `tools/build.py`، ثم شغّل `python3 tools/build.py`. هذا يحدّث الصفحة والأسئلة والبيانات المنظمة معًا.
- **لتغيير سريع دون بناء:** عدّل `CONFIG` في أسفل `index.html`. هذا يغيّر الأرقام الظاهرة في الصفحة فقط، وتبقى نصوص الوصف والأسئلة على القديم.

## الملفات
| المسار | ما فيه |
|---|---|
| `index.html` | الصفحة الجاهزة (تُبنى، لا تُعدّل باليد إلا `CONFIG`) |
| `tools/template.html` | التصميم والنصوص الثابتة والسلوك |
| `tools/build.py` | **الإعدادات:** السعر، ورابط الدفع، والمسار المفتوح أولًا، والأسئلة. ويبني `index.html` |
| `data/books.json` | الخلاصات الـ99 بعناوينها ومؤلفيها، ووصف كل مسار، منقولة من الصفحة السابقة |
| `tools/assets.sh` | يصنع صور `assets/` من ملفات PDF الستة |
| `tools/og.mjs` | يصنع صورة المشاركة من الأغلفة |
| `tools/shots.mjs` | لقطات مراجعة للجوال والحاسوب |

## إعادة البناء
```sh
tools/assets.sh <مجلد ملفات PDF: S1.pdf … S6.pdf>   # الأغلفة والصفحتان (لا تُرفع إلى المستودع العام)
node tools/og.mjs                                   # assets/og-image.jpg
python3 tools/build.py                              # index.html
node tools/shots.mjs review/x                       # لقطات المراجعة
```
