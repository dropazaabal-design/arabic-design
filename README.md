# arabic-design

إضافة Claude تجعله **مدير تصميم عربي داخل Canva**: يصمّم بنفسه منشورات وريلات
وإعلانات عالية الجرافيك، ويحرس عربيّتها، ويتذكّر ذوق صاحبها. عبر موصّل Canva MCP.

العربية في أدوات التصميم تفشل في طبقات متراكبة: الاتجاه، والـBiDi، والترقيم،
والأرقام، والتنضيد، والخطوط، وانعكاس التخطيط، ومقاسات الصناديق، وجودة النص،
والوصولية — ونصّ يعيد المولّد صياغته. هذه الإضافة تعالجها كمنظومة.

---

## ثلاث أفكار محوريّة

### ١. Claude يصمّم في Canva، والإضافة بوّابة العربية

Canva يولّد الجرافيك: رسم تحريري أو صورة، وتكوين. والعربية التي تخرج منه تحتاج
حارسًا — على أول منشور جُرّب أسقط المولّد «٦» من العنوان، وكتب «ترتّيت» مكان
«تربّيت»، وغطّى أول كلمة من كل نقطة بشارة الرقم. الإضافة التقطت ذلك كله وأصلحته
في معاملة واحدة بمعاينة وموافقة.

```
نصّ صاحبه → الموجز (أسطره الحرفية) → create-design + generate-image
          → read-design → plan --expect → reflow → معاينة → موافقة → commit
```

وطريق ثانٍ لما يحتاج تنضيدًا عربيًا دقيقًا بخطوط حقيقية على إطارات متتابعة:
صفحة HTML تُستورد (`make`). يمرّ بنشر عام على GitHub، فلا يُسلك إلا **بإذن صريح
لكل تصميم**.

### ٢. ما يعمل في محرّر Canva مقيس لا مفترَض

Canva لا يملك معاملًا لاتجاه النص، ولا يُرجع اتجاه الصندوق. قيس ما يعمل على تصميم
حيّ، متغيّرًا واحدًا في كل مرة:

```
RLM بعد «غيرك.»                  →  النقطة في طرفها الصحيح        ✅
LRM على جانبي «@kitabwbs»        →  الحساب سليم                  ✅
RLE/PDF ،  LRI/PDI               →  تُخزَّن وتُتجاهَل             ❌
replace_text                     →  يقلب الصندوق يساريًا ويوحّد ألوانه  ❌
find_and_replace_text            →  يحفظ الاتجاه والتنسيق         ✅
```

فالتصحيح **كلمةٌ بكلمة ومراسٍ لا أغلفة**. والنص يُخزَّن بالترتيب المنطقي دائمًا
— محارف تحكّم فقط، لا إعادة ترتيب بصري. التفاصيل: `REFERENCE.md` §٢.

### ٣. نصّ صاحبه هو الجواب

المعجم يرى «ترتّيت» كلمة ملتبسة بين ثلاث — ومحقّ ألّا يختار. لكن حين يكون سطر
صاحبها معروفًا فلا التباس: `plan --expect` يعيد الكلمة المحرّفة والحركات الساقطة
منه، ويبلّغ عن الكلمة الغائبة مع عملية تعيدها.

## التثبيت

من GitHub مباشرة:

```bash
claude plugin marketplace add dropazaabal-design/arabic-design
claude plugin install arabic-design@arabic-design
```

أو من نسخة محلّية:

```bash
git clone https://github.com/dropazaabal-design/arabic-design
cd arabic-design
claude plugin marketplace add ./          # الشرطة المائلة ضرورية
claude plugin install arabic-design@arabic-design
```

للتحقّق: `claude plugin details arabic-design@arabic-design` — يجب أن يعرض سبع مهارات.

يتطلّب Node ≥ 18 وموصّل Canva MCP متصلًا. بلا اعتماديات خارجية.

## ما يُصلَح آليًا وما لا يُصلَح

هذا الفصل هو جوهر الإضافة. **لا تدّعي إصلاح ما لا تستطيعه الواجهة.**

**✅ آليًا** — نصّ صاحبه (`--expect`)، الترقيم في طرفه الصحيح، الحسابات
والروابط والهواتف داخل العربية، ترتيب الأقواس، الترقيم العربي، توحيد الأرقام،
الحركات المفبركة، حذف التمطيط، إلغاء الميل الاصطناعي، ارتفاع سطر المتن، حجم
النقطة، إعادة الملاءمة من قياس، انعكاس المواضع والقلب.

**👁 بعد النظر في المصغّرة** — المحاذاة (`--align=end` لصندوق يساري)، إعادة كلمة
ساقطة، تقصير صندوق تحت شارة، التراكب.

**❌ يدويًا** — نوع الخط، **تباعد الأحرف**، تحويل الحالة، اتجاه الصندوق، وكل
تنضيد على صفحة `is_responsive`.

## المكتبات

```
lib/bidi.js         مراسي RLM/LRM للتحرير، وأغلفة RLE/LRI لصفحات الاستيراد، الترقيم، الأقواس
lib/verbatim.js     نصّ التصميم مقابل أسطر صاحبه: يعيد المحرّف ويبلّغ الساقط
lib/taste.js        ذاكرة الذوق: نطاقات، ودليل من كلام المستخدم، وتاريخ
lib/numerals.js     أنظمة الأرقام الثلاثة، التواريخ، العملات
lib/typography.js   قواعد المنع والمقاسات، ونص العرض، والمحاذاة المُبلَّغة
lib/detect.js       الخطوط، أعطال المحارف، التباين، الانعكاس، هندسة مقيسة
lib/spelling.js     قواعد بنيوية + معجم ومسافة تحرير خلف بوّابة
lib/lexicon/        ١٧٠٬٤١٢ كلمة بتردّداتها (MIT) — ٠٫٨٥MB مضغوطة
lib/from-read.js    استجابة Canva → حمولة، مع z من ترتيب الرسم وعدد التنسيقات
lib/cli.js          plan (كلمات ونمط) ثم reflow (هندسة مقيسة)، وmake
lib/outline.js      المنشور كما يُكتب → مخطّط، بأسطر مكسورة حيث يكسرها إنسان
lib/compose.js      مخطّط → صفحة يبتلعها مستورِد Canva، + فحص استيراد ونشر
lib/patterns.js     هندسة إسلامية مولَّدة وأيقونات خطّية
lib/recipes.js      ١٢٠٠ مظهر: لوحات × خطوط × أنماط × تخطيطات + مقاسات فيسبوك
lib/copy.js         الكابشن، كليشيهات المولّدات العربية، طُعم فيسبوك
taste.json          ذوق صاحب المشروع بكلماته
```

بوّابة العربية على تصميم في Canva — **قِس ولا تخمّن**:

```bash
node lib/from-read.js read.json > payload.json
node lib/cli.js plan payload.json --expect=lines.txt       # كلمات ونمط
#   → أرسلها بـ finalize: "keep_open"؛ الاستجابة تحمل الارتفاعات الحقيقية
node lib/from-read.js after.json > measured.json
node lib/cli.js reflow measured.json                        # تقاطع وحجاب وخروج
```

## قرارات تصميمية تستحق التوضيح

**التصحيح كلمةٌ بكلمة.** `replace_text` بالنص نفسه حرفًا بحرف قلب فقرة عربية إلى
اليسار ونقل نقطتها، وأعاد عنوانًا بلونين بلون واحد. `find_and_replace_text` على
الكلمة يحفظ الاثنين. حين لا يُقال التغيير كلمةً بكلمة يُعاد النص كاملًا ومعه
`text_align: end`، إلا الصندوق متعدّد التنسيق: يُبلَّغ ولا يُمسّ.

**المحاذاة تُقرأ من المصغّرة.** `start` نفسها يمينٌ في صندوق صنعه Canva للعربية
ويسارٌ في صندوق من قالب يساري، والقراءة لا تفرّق. القاعدة القديمة «start ← end
دائمًا» كانت تعوّض أثر `replace_text` الذي كانت الخطة تستعمله لكل نص، فحين
توقّف توقّفت.

**نص العرض يُترك مضغوطًا.** 1.8 لكل عربي كان يدفع عنوانًا بحجم 110px فوق ما
تحته. من 60px فما فوق، ارتفاع السطر قرار المصمّم.

**الحجاب علاجان.** شارة رقم صغيرة عند طرف السطر: يُقصَّر الصندوق ليقف قبلها —
رفع النص فوقها يطبع الكلمات عليها. حجاب كبير: `layer_element`. وتصغير الخط ليس
علاجًا في الحالتين.

**لا تقديرات.** مقدّر فيض قديم اقترح تصغير ١٤ عنصرًا من ١٤ لأنه افترض صناديق
ثابتة الارتفاع، وصناديق Canva تنمو وحدها. حُذف، ولم يُكتب بديل يخمّن.

**المدقّق الإملائي دقّة لا شمول.** معجم ١٧٠ ألف كلمة ومسافة تحرير واحدة، ولا
يُطبَّق تصحيح آليًا إلا التباس نقاط أو تبديل موضعين لمرشّح شائع يغلب منافسه
بخمسة عشر ضعفًا — `كايزن` لا تصير `كاين`. ما دون ذلك يُعرض ولا يُختار.

**الأقواس لا تُقلب في المصدر.** قاعدة Unicode L4 تقلبها عند العرض؛ `fixBracketOrder`
يصلح فقط ما قلبه إنسان يدويًا.

**إحصاء خلط الأرقام يتجاهل الروابط والهواتف.** رقم هاتف بأرقام لاتينية ليس خلطًا.

## تحذير التصدير

النصوص التي تحمل علامات الاتجاه تحملها معها عند النسخ خارج Canva. معظم التطبيقات
تتعامل معها بسلام، لكن حقول النص العادي التي تنزعها ستفقد الاتجاه. للاستعمال
خارج التصميم: `bidi.stripBidiControls(text)`.
