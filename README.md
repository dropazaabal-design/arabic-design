# arabic-design

إضافة Claude لتصحيح التصاميم العربية في Canva عبر موصّل Canva MCP.

ليست إضافة «خط واتجاه». العربية في أدوات التصميم تفشل في عشر طبقات متراكبة:
الاتجاه، والـBiDi، والترقيم، والأرقام، والتنضيد، والخطوط، وانعكاس التخطيط،
ومقاسات الصناديق، وجودة النص، والوصولية. هذه الإضافة تعالجها كمنظومة.

---

## فكرتان محوريّتان

### التوليد: ارسم خارج Canva، وسلّم إليها

عمليات Canva للرسم لا تصنع تدرّجًا ولا تغيّر خطًّا ولا ترسم نمطًا. لكن
**مستورِد HTML عندها يفعل الثلاثة** — يرسم الصفحة بنفسه ثم يعيدها طبقات حقيقية:
النصّ نصًّا قابلًا للتحرير، وخطوط Google مطابَقة بخطوط Canva، وما بقي مُرسَّمًا.

```
مفهوم → نصّ عربي مدقّق + لوحة مضمونة التباين + نمط مولَّد
      → HTML بقواعد الاستيراد → مستودع عام → raw.githubusercontent
      → import-design-from-url → تصميم Canva بطبقات حيّة
```

قواعد الاستيراد الستّ في `REFERENCE.md` §١٢، وكلٌّ منها إخفاق مقيس على
المستورِد الحقيقي لا تخمينًا. `lintForImport()` يفرضها.

### التصحيح: الفكرة المحورية

Canva لا تملك أي معامل لاتجاه النص. لا في `format_text`، ولا في أي عملية أخرى.
المخرج الوحيد الذي يعمل هو **محارف التحكّم Unicode مضمَّنة في النص نفسه**:

```
U+202B (RLE) + السطر العربي + U+202C (PDF)   →  يفرض اتجاه الفقرة RTL  ✅
U+2066 (LRI) + مقطع لاتيني  + U+2069 (PDI)   →  يعزل المقطع عن محيطه   ✅
U+200F (RLM) وحده                             →  لا يعمل في Canva       ❌
```

العزل بـ LRI/PDI لا بـ LRE/PDF: التضمين يسرّب الاتجاه إلى المحايدات المجاورة،
والعزل يمنعه. هذا الفرق هو ما يجعل `+966 50 123 4567` يبقى سليمًا داخل جملة
عربية بدل أن تهاجر إشارة `+` إلى الطرف الخطأ.

**النص يُخزَّن بالترتيب المنطقي دائمًا.** لا إعادة ترتيب بصري — النص عندها غير
قابل للتحرير ولا للنسخ داخل Canva. محارف تحكّم فقط.

## التثبيت

من GitHub مباشرة:

```bash
claude plugin marketplace add dropazaabal-design/arabic-design
claude plugin install arabic-design@arabic-design
```

أو من نسخة محلّية:

```bash
git clone https://github.com/dropazaabal-design/arabic-design
cd arabic-design
claude plugin marketplace add ./          # الشرطة المائلة ضرورية
claude plugin install arabic-design@arabic-design
```

للتحقّق: `claude plugin details arabic-design@arabic-design` — يجب أن يعرض أربع مهارات.

يتطلّب Node ≥ 18 وموصّل Canva MCP متصلًا. بلا اعتماديات خارجية.

## المهارات

| المهارة | ماذا تفعل |
|---|---|
| `/arabic-create` | **تولّد** تصميمًا عربيًا عالي الجرافيك وتسلّمه قابلًا للتحرير في Canva. |
| `/arabic-audit` | تفحص وتصدر تقريرين — آلي ويدوي. **لا تعدّل شيئًا.** |
| `/arabic-fix` | تصحّح ما تستطيعه الواجهة، بمعاينة وموافقة صريحة قبل الحفظ. |
| `/arabic-mirror` | تعكس التخطيط لقراءة RTL، وتستثني ما لا ينعكس. |
| `/arabic-typeset` | قواعد التنضيد والمقاسات وبدائل الخطوط ومقابلة الأوزان. |

للتوليد: `/arabic-create`. للتصحيح: `/arabic-audit` لترى الحال، ثم
`/arabic-fix` لتطبّق، ثم `/arabic-mirror` إن كان التخطيط اتجاهيًا.

المولِّد والمصحّح يعملان معًا: الأول يبني، والثاني يتحقّق بالقواعد نفسها.

## ما يُصلَح آليًا وما لا يُصلَح

هذا الفصل هو جوهر الإضافة. **لا تدّعي إصلاح ما لا تستطيعه الواجهة.**

**✅ آليًا** — اتجاه RTL، عزل اللاتيني والأرقام والروابط والبريد والهواتف، ترتيب
الأقواس، الترقيم العربي، توحيد الأرقام، الحركات المفبركة، حذف التمطيط، إلغاء
الميل الاصطناعي، ارتفاع السطر، حجم النقطة، المحاذاة إلى `end`، إعادة الملاءمة
من قياس، انعكاس المواضع والقلب.

**❌ يدويًا** — نوع الخط، **تباعد الأحرف**، تحويل الحالة، وكل تنضيد على صفحة
`is_responsive`.

تباعد الأحرف أهمّها: `format_text` لا يملك حقلًا له، فالقاعدة تبقى صارمة
(صفر دائمًا على العربية) والتنفيذ يدوي. الإضافة تبلّغ عنه ولا تزعم إصلاحه.

## المكتبات

```
lib/bidi.js         RLE/PDF, LRI/PDI, العزل، الترقيم، ترتيب الأقواس، القصّ
lib/numerals.js     أنظمة الأرقام الثلاثة، التواريخ، العملات
lib/typography.js   قواعد المنع والمقاسات والمحاذاة
lib/detect.js       الخطوط، أعطال المحارف، التباين، الانعكاس، هندسة مقيسة
lib/spelling.js     قواعد بنيوية + معجم ومسافة تحرير خلف بوّابة
lib/lexicon/        ١٧٠٬٤١٢ كلمة بتردّداتها (MIT) — ٠٫٨٥MB مضغوطة
lib/from-read.js    استجابة Canva → حمولة، مع z من ترتيب الرسم
lib/cli.js          plan (نص ونمط) ثم reflow (هندسة مقيسة)
lib/compose.js      مفهوم → صفحة يبتلعها مستورِد Canva، + فحص استيراد ونشر
lib/patterns.js     هندسة إسلامية مولَّدة وأيقونات خطّية
lib/recipes.js      ١٢٠٠ تركيبة: لوحات × خطوط × أنماط × تخطيطات + مقاسات فيسبوك
tools/              إعادة بناء المعجم من المصدر
```

**التوليد بأمر واحد** — مخطّط نصّي ← صفحة جاهزة للنشر:

```bash
node lib/cli.js make outline.json --reel --format=reel \
  --palette=midnight --pairing=kufic --pattern=girih --repo=owner/name
```

ثم النشر على raw.githubusercontent والاستيراد إلى Canva، و`export-design` بـmp4
للريل. خمسة إطارات = ٢٥ ثانية.

---

دورة التمريرتين للتصحيح — **قِس ولا تخمّن**:

```bash
node lib/from-read.js read.json > payload.json
node lib/cli.js plan payload.json --numerals=arabic-indic   # نص ونمط
#   → أرسلها بـ finalize: "keep_open"؛ الاستجابة تحمل الارتفاعات الحقيقية
node lib/from-read.js after.json > measured.json
node lib/cli.js reflow measured.json                        # تقاطع وخروج
```

كاشفان على أرقام مقيسة: **تقاطع المستطيلات** (تلامس الحواف ليس تقاطعًا) و**الخروج
من الحاوية** (الحاوية تُعرف بركن النص وعرضه، لا بمساحته). التراكب يُبلَّغ ولا
يُدرَج — إزاحة عنصر قد تدفعه فوق ثالث ولا توجد تمريرة ثالثة تكتشف ذلك.

`lib/spelling.js` و`lib/from-read.js` ليسا في البنية الأصلية المطلوبة. الأول
فُصل عن `detect.js` لأنه قواعد لغوية لا كشفًا هندسيًا؛ والثاني يحذف خطوة نسخ
يدوي كانت أكثر الخطوات عرضة للخطأ.

## قرارات تصميمية تستحق التوضيح

**الأقواس لا تُقلب في المصدر.** قاعدة Unicode L4 تقلب الأقواس عند العرض، فكتابة
`)` مكان `(` تعني قلبًا مزدوجًا وتصميمًا مكسورًا. `fixBracketOrder` يترك الأزواج
السليمة ويصلح فقط ما قلبه إنسان يدويًا (`)نص(`).

**العزل لا يشمل الأرقام الهندية.** `٠١٢٣` من فئة AN وتتصرّف صحيحًا داخل فقرة
RTL؛ عزلها بـ LRI يفرض عليها LTR بلا داعٍ. العزل للأرقام اللاتينية فقط.

**إحصاء خلط الأرقام يتجاهل الروابط والهواتف.** رقم هاتف بأرقام لاتينية ليس
«خلطًا» — لولا هذا الاستثناء لأبلغت الإضافة عن كل تصميم عربي إلى الأبد.

**المدقّق الإملائي دقّة لا شمول.** كل قاعدة فيه قاعدة يقبلها محرّر بشري بلا
تردّد. `علي` لا تُصحَّح إلى `على` لأنها اسم عَلَم بقدر ما هي حرف جرّ — تُبلَّغ
ولا تُغيَّر.

**لا تقديرات.** كان هنا مقدّر فيض يحسب عرض المحارف؛ على تصميم حقيقي اقترح
تصغير ١٤ عنصرًا من ١٤ بنسب ٢٥–٣٥٪ لأنه افترض صناديق ثابتة الارتفاع، وصناديق
Canva تنمو وحدها (110.77px ← 128.17px برفع `line_height` فقط). حُذف، ولم يُكتب
بديل يخمّن. الهندسة تُقرأ من استجابة `edit-design` بعد إعادة التدفّق.

**المدقّق الإملائي: معجم ١٧٠ ألف كلمة ومسافة تحرير واحدة، خلف بوّابة ضيّقة.**
`كايزن` مسافة حذف واحدة عن `كاين`، و`غامان` مسافة إبدال عن `بأمان` — وتصحيح اسم
منقول أسوأ من ترك خطأ مطبعي. فلا يُطبَّق تصحيح آليًا إلا إذا كان التعديل **التباس
نقاط أو تبديل موضعين** (`ف/ق` نعم، حذف حرف لا)، والمرشّح شائعًا، ويغلب منافسه
بخمسة عشر ضعفًا. ما دون ذلك اقتراح للإنسان.
كلمة صحيحة في غير موضعها (`غدد` مكان `غدًا`) خارج متناول أي معجم، والتقرير يقولها.

**الطبقات تفصل التظليل عن الحجاب.** شكل يتقاطع مع نص شيئان مختلفان: خلفه شريط
تظليل مقصود فصامت، أمامه حجاب يخفي سطرًا فعلاجه `layer_element` لا تصغير الخط.

## تحذير التصدير

النصوص المغلَّفة بمحارف التحكّم تحمل تلك المحارف معها عند النسخ خارج Canva.
معظم التطبيقات تتعامل معها بسلام، لكن حقول النص العادي التي تنزعها ستفقد
الاتجاه، وأدوات استخراج النص من PDF قد ترتّب المقاطع ترتيبًا غريبًا.

إن كان النص سيُعاد استعماله خارج التصميم فاحتفظ بنسخة نظيفة:
`bidi.stripBidiControls(text)`.

التفاصيل الكاملة في [`REFERENCE.md`](REFERENCE.md).
