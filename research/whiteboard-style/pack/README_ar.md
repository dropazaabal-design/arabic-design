# حزمة مرجع أسلوب الفيديو

ابدأ بقراءة `visual_style_reference_ar.md`.

- **المرجع المكتوب:** `visual_style_reference_ar.md` — قواعد ثابتة للرسم والتكوين والشخصيات والنص والحركة.
- **الطلب الجاهز:** `start_here_ar.txt` — غيّر الموضوع والفكرة والمدة والمقاس ثم أرسله إلى المنفّذ.
- **لوحة المراجع:** `reference_board.jpg` — 14 عينة مصغرة.
- **الصور الأصلية:** `frames/` — 14 فريمًا بدقة 1280×720.
- **مثال الحركة:** `motion_samples.jpg` — 13 عينة بين 00:10 و00:13، بفاصل 0.25 ثانية.
- **فهرس الصور:** `reference_index.json` — توقيت كل صورة ورقم فريمها ودورها البصري.
- **قالب المشاهد:** `scene_plan_template.json` — قالب يُملأ بعد تحديد الموضوع والصوت.

إذا أردت رفع ملف واحد صغير فقط، ارفع المرجع المكتوب. ولتثبيت الشكل بصريًا، أرفق معه لوحة المراجع أو الحزمة كاملة إذا كان المنفّذ يستطيع فك ZIP وقراءة الصور.

هذه الحزمة توجّه إنتاج موضوعات جديدة بنفس ملامح الأسلوب. لا تحتوي فيديو جديدًا ولا تدّعي ضمان المطابقة الحرفية بنسبة 100%.
