# تجربة OmniSVG وOmniLottie على GPU — خطة جاهزة للتشغيل

**الحالة**: جاهزة ولم تُنفَّذ. لم يُستأجر GPU، ولم تُنزَّل أوزان، ولم يُصرف شيء. تنتظر اختيار البيئة والميزانية.

**السؤال**: هل يحسّن أحد المولّدين ريلات «كتاب وبس» إذا قيس على شخصية وغرض من قصة EP04؟ نقيس ثلاثة أشياء مقابل المسار الحالي (SVG مرسوم ← SVGR ← هيكل حركة ← Remotion):

1. الجودة؛
2. سهولة التعديل؛
3. وقت الإصلاح.

## 1. ما نعرفه قبل التشغيل (من المستودعات الرسمية، 16 أكتوبر 2026)

| | OmniSVG | OmniLottie |
|---|---|---|
| **المستودع** | https://github.com/OmniSVG/OmniSVG | https://github.com/OpenVGLab/OmniLottie |
| **الأوزان** | `OmniSVG/OmniSVG1.1_4B` ‏(7.69GB)، و`OmniSVG/OmniSVG1.1_8B` ‏(17.2GB) | `OmniLottie/OmniLottie` ‏(4B، ‏8.46GB) |
| **ذاكرة GPU المعلنة** | ‏4B: ‏17GB، و‏8B: ‏26GB | ‏15.2GB |

| **المدخلات** | نص، أو صورة | نص، أو صورة ونص، أو فيديو |
| **المخرج** | SVG ثابت | Lottie JSON |

| **الأساس** | ‏Qwen2.5‑VL، بحسب وسم المعمارية في بطاقة النموذج | ‏Qwen2.5‑VL‑3B يظهر كمرمّز في المثال، والأساس الفعلي غير مسمى |

| **ترخيص الأوزان** | يقول README إن ملفات الترخيص في GitHub وHugging Face، ولم نقرأ ملف الأوزان نفسه | ملخص README: الكود والأوزان Apache‑2.0، ولم نقرأ ملف الأوزان نفسه |
| **ترخيص البيانات** | ‏MMSVG: ‏CC BY‑NC‑SA 4.0 | ‏MMLottie‑2M: ‏CC BY‑NC‑SA 4.0، والاستعمال المقصود بحثي غير تجاري |
| **العرض الرسمي** | Space ‏`OmniSVG/OmniSVG-3B` (الإصدار القديم 3B) | Space ‏`OmniLottie/OmniLottie` |

**ملاحظات**:
- **الوصول من هنا**: موقع Hugging Face محجوب من بيئة الإنتاج (الجلب المباشر وcurl). لذلك لم نفتح بطاقتي الأوزان ولا العرضين الرسميين. سكربت التشغيل ينسخ ملفات الترخيص الفعلية من مستودعات الأوزان إلى `licenses/` ليُقرأ نصها قبل أي اعتماد.
- **الترخيص**: البيانات غير تجارية. هل يمتد ذلك إلى المخرجات؟ هذا سؤال قانوني لا نجيب عنه من هنا. النشر في حساب عام يحتاج قراءة شروط الأوزان أولًا.
- **حدود الأداتين بحسب المستودعين**: لا يَعِد أي منهما بأجزاء دلالية مسماة، ولا بهيكل حركة، ولا بإمساك أغراض.

## 3. مساران للتشغيل

### المسار 0: العروض الرسمية (بلا تكلفة، يُشغَّل من متصفحك)

- **OmniSVG (الإصدار 3B)**: الصق الوصف الأول والثالث، وارفع `naser.png` و`clock.png`، ونزّل ناتج SVG.
- **OmniLottie**: الصق الأوصاف الثلاثة، وارفع `naser.png` مع وصف الحركة، وجرّب الفيديو إن قبله العرض. نزّل ملفات JSON.

أرسل لي الملفات، فأحللها هنا بلا GPU.

| المزايا | الحدود |
|---|---|
| صفر تكلفة ضمن الحصة المجانية لـZeroGPU، وهي دقائق يوميًا، وPRO يرفعها إلى 40 دقيقة يوميًا بـ9 دولارات شهريًا | OmniSVG هنا هو الإصدار القديم 3B |
| يحسم سؤال «هل يستحق الأمر GPU؟» قبل أي إنفاق | لا قياس للذاكرة والزمن |
| | رفع رسوماتنا إلى خدمة عامة، فلا ترفع ما لا تريد نشره |

### المسار 1: GPU مستأجر (الاختبار الكامل والقابل للقياس)

**العتاد**:

| البطاقة | ما تشغّله |
|---|---|
| **L40S ‏48GB (الموصى به)** | النماذج الثلاثة، ومنها OmniSVG 8B |
| RTX 4090 ‏24GB | OmniSVG 4B وOmniLottie فقط، والسكربت يتخطى 8B تلقائيًا |
| A100 ‏80GB | يعمل، لكنه أغلى بلا حاجة |

**القرص**: نحو 120GB، منها نحو 35GB أوزان، والباقي للحزم والمخرجات.

**الأوامر** (على الجهاز المستأجر، بصلاحية root):

```sh
git clone --depth 1 -b claude/new-session-6t6hh9 https://github.com/dropazaabal-design/arabic-design
export WORK=/workspace/omni TRIAL=$PWD/arabic-design/research/omni-gpu-trial
bash $TRIAL/scripts/setup.sh          # بيئتان، الأوزان، ملفات الترخيص، التزامات الكود (نحو 45–60 دقيقة)
bash $TRIAL/scripts/run_omnisvg.sh    # 4 أوصاف و4 صور × 4 مرشحات × (4B و8B) = 64 توليدًا
bash $TRIAL/scripts/run_omnilottie.sh # 3 أوصاف، وصورتان، وفيديو × 4 مرشحات، و4 صورة+وصف = 28 توليدًا
bash $TRIAL/scripts/pack.sh           # omni-trial-results.tgz: المخرجات والسجلات والتراخيص
```

**ما تحتاجه البيئة**: إن كان المستودع خاصًا، فالاستنساخ يحتاج رمز وصول للقراءة فقط. البديل: انسخ المجلد `research/omni-gpu-trial` وحده إلى الجهاز.

**بعد التشغيل**: أعد `omni-trial-results.tgz` إلى هذه الجلسة. التحليل والمقارنة يجريان هنا بلا GPU:
- `scripts/analyze.py` للأرقام البنيوية؛
- تركيبة Remotion تعرض كل ناتج بجانب نظيره من المسار الحالي، بحجم الهاتف وبالرمادي، وتشغّل Lottie عبر `@remotion/lottie`.

## 6. معيار القرار

نعتمد أداة لدور محدد فقط إذا تحققت كل الشروط:

1. ناتجها مقروء بحجم الهاتف على مدخلنا.
2. **OmniSVG**: إصلاح أفضل مرشح وتقسيمه إلى أجزاء أسرع من رسم الأصل يدويًا في `sultan.svg`. الدور المتوقع إن نجح: مسودة لأغراض وخلفيات جديدة، لا للشخصية المتحركة.
3. **OmniLottie**: ناتجه يمكن إعادة توقيته على الكلمات، ويبقى فيه الإمساك والطبقات سليمة. وإلا فدوره زخرفي فقط: انتقال أو أيقونة.
4. ترخيص الأوزان يسمح بالنشر في حساب عام.

إن لم يتحقق ذلك نكمل بالمسار الحالي، ونسجّل الدليل في `reels/cr1-ep04-saa-w-akhallis/review/tools-decision.md`. وفي الحالتين تُستأنف EP04 من `reels/cr1-ep04-saa-w-akhallis/PAUSED.md`.
