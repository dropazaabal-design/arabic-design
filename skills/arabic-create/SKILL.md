# توليد تصميم عربي

اقرأ `REFERENCE.md` §٧ (دورة التمريرتين) و§١٢ (مسار النشر) قبل البدء.

## الفكرة التي تجعل هذا ممكنًا

عمليات Canva للرسم لا تصنع تدرّجًا، ولا تغيّر خطًّا، ولا ترسم نمطًا. **لكن
مستورِد HTML عندها يفعل الثلاثة**، لأنه يرسم الصفحة بنفسه ثم يعيدها طبقات
Canva حقيقية: النصّ نصًّا قابلًا للتحرير، وخطوط Google مطابَقة بخطوط Canva
نفسها، وما بقي مُرسَّمًا في مكانه.

فالتصميم يُؤلَّف HTML ويُستورَد. هذا مُثبَت بالتجربة لا مفترَضًا:

```json
{ "type": "text", "characters": "الجمالُ\nفي التفصيل",
  "fontSize": 132, "lineHeight": 1.18, "fontRef": "YAFdJg45t1g,0" }
```

## الخطوات

### ١. المفهوم — ثلاثة اتجاهات، لا واحد

من موجز، أو من موضوع مجرّد، أو من لا شيء: **اعرض ثلاثة مفاهيم قبل أن تُسأل.**
لكل واحد: زاوية، ونصّ عربي كامل، ولوحة، وخطّان، ونمط، وتخطيط.

اختلافها يجب أن يكون في **الزاوية لا في اللون**: مفهوم يبدأ من سؤال، وآخر من
رقم، وثالث من مفارقة. ثلاث لوحات لنفس الفكرة ليست ثلاثة مفاهيم.

### ٢. اكتب النصّ عربيًا، لا مترجَمًا

النصّ العربي الجيّد أقصر من الإنجليزي. عنوان من كلمتين أقوى من جملة. تجنّب
التركيب المترجَم («نحن نقدم لكم أفضل الحلول») واكتب كما يُقال.

**لا تدقّق النصّ بنفسك** — `compose` يمرّره على المدقّق ومحرّك الاتجاه وتوحيد
الأرقام، ويعيد لك `notes` بما غيّره. اقرأها: إن صحّح كلمة لم تقصدها، غيّر
النصّ لا القاعدة.

### ٣. ألّف

```js
const { compose, lintForImport, publishTarget } = require('${CLAUDE_PLUGIN_ROOT}/lib/compose');

const spec = {
  title: 'الجمال في التفصيل',
  size: { width: 1080, height: 1350 },
  palette: { bg:'#0B1F2A', ink:'#F5EFE0', body:'#D8CEB8', muted:'#BDB49F', accent:'#C9A227' },
  fonts:  { display: 'Tajawal', body: 'Amiri' },
  pattern:{ kind: 'girih' },              // girih | zellij | rays | none
  glow:   'radial-gradient(1100px 680px at 82% -8%, #1C6B5A 0%, transparent 62%)',
  blocks: [
    { role:'eyebrow', text:'سلسلة الإتقان' },
    { role:'title',   text:'الجمالُ\nفي التفصيل' },
    { role:'body',    text:'…' },
    { role:'cards',   items:[{num:'01',label:'…'}] },
    { role:'footer',  start:'2026', end:'استوديو أزابال' },
  ],
};

const { html, issues, notes } = compose(spec, { numerals: 'arabic-indic' });
```

`issues` تحمل إخفاقات التباين — **لا تنشر وفيها خطأ**، غيّر اللون.
سلّم المقاسات وارتفاعات السطور تُشتقّ من ارتفاع اللوحة وتحترم حدود العربية
تلقائيًا؛ لا تكتبها بنفسك.

### ٤. افحص قبل النشر

```js
lintForImport(html)   // [] أو أخطاء
```

كل قاعدة فيه إخفاق مقيس على المستورِد الحقيقي — راجع §١٢. إن رجع بشيء فأصلحه
قبل أن تنفق استيرادًا.

### ٥. انشر

المستورِد يقبل رابط HTTPS عامًّا فقط، و`raw.githubusercontent.com` يصلح
مباشرةً رغم أنه يقدّم `text/plain` (مُختبَر). فلا وسيط ولا مستضيف ملفّات غريب،
والمحتوى يبقى على حساب يملكه المستخدم.

1. حدّد مستودعًا **عامًّا** للنشر (`get_me` ثم `search_repositories`). إن لم
   يوجد فأنشئه بـ `create_repository` باسم `arabic-design-published`، عامًّا.
2. `publishTarget({ owner, repo, branch, html })` يعطيك المسار والرابط.
   المسار يحمل بصمة المحتوى، فكل نشرة رابط جديد — وهذا يتجاوز تخزين CDN
   المؤقّت الذي أضاع لي محاولة كاملة.
3. `create_or_update_file` بمحتوى `html`.

> **قل هذا للمستخدم صراحةً**: الصفحة تصير **عامّة** على GitHub حتى يجلبها
> Canva. هذا لازم لأي مسار استيراد. احذفها بعد النجاح إن كان النصّ حسّاسًا.

### ٦. استورد وتحقّق

```
import-design-from-url(url, name, intended_design_type)
read-design(design_id, filter: { fields: ["thumbnails"] })
```

**انظر إلى الصورة المصغّرة فعلًا.** ثم شغّل `plan` على التصميم المستورَد
(مهارة `/arabic-fix`) — المولِّد والمصحّح يعملان معًا: الأول يبني، والثاني
يتحقّق بالقواعد الـ١٩٨ نفسها.

## الأدوار المتاحة

| الدور | الشكل |
|---|---|
| `topbar` | شريط علوي ملوّن بأيقونة، `{height, bg, rule, icon, text}` |
| `eyebrow` `title` `body` | تُجمَّع تلقائيًا كوحدة رأسية |
| `cards` | بطاقات مختصرة `{num, label}` |
| `list` | بطاقات مرقّمة بعنوان وشرح `{num, title, body}` |
| `closing` `question` | نصّ وسطيّ |
| `brand` `footer` | سطر التوقيع |

`icon('tree'|'rose'|'hand'|'spark'|'quote')` من `lib/patterns` — أيقونات خطّية
مولَّدة لا مستورَدة، تأخذ لون اللوحة.

## المقاسات: احسبها أو أملِها

سلّم المقاسات يُشتقّ من ارتفاع اللوحة تلقائيًا. لكن تصميمًا بثمانية مكوّنات لا
يسعه سلّم مشتقّ من اللوحة وحدها، فمرّر `spec.sizes` صراحةً:

```js
sizes: { title: 56, itemTitle: 32, itemBody: 30, closing: 34, question: 34, brand: 24 }
```

**الحدّ الأدنى للعربية غير قابل للتفاوض**: أي مقاس دونه يُرفع ويُبلَّغ في
`issues`، ولا يُطاع صامتًا.

## صفحات متعدّدة حين لا يتّسع

`spec.pages = [{label, blocks}, …]` ينتج تصميم Canva متعدّد الصفحات — المستورِد
يصنع صفحة من كل عنصر يحمل `data-document-role="page"`.

**هذا هو الجواب الصادق حين لا يتّسع المحتوى.** ستّ بطاقات وخاتمة وسؤال وسطر
علامة قيست **2618px** على لوحة 1920px. لا تصغّر الخط حتى يتّسع — اقسمه.

**قِس قبل أن تستورد.** إن توفّر متصفّح محلّي، صيّر الصفحة واقرأ
`scrollHeight` لكل `.page`. وإلا فاستورد واقرأ المصغّرات.

### ٧. اعرض واسأل

اعرض المصغّرة والرابط، واسأل عن الاتجاه التالي: تغيير اللوحة؟ نمط آخر؟
مقاس ثانٍ (ستوري، غلاف)؟ نفس المفهوم بمقاسات متعدّدة يُولَّد بتغيير `size`
وحده — سلّم المقاسات يعيد حساب نفسه.

## قواعد التأليف — كلٌّ منها إخفاق مقيس

| القاعدة | ما حدث حين خولفت |
|---|---|
| **اربط الخطوط، لا تضمّنها** | صفحة بثلاثة خطوط base64 = ٨٤٥KB، رُفضت: «محتوى أكثر من اللازم». والربط أفضل: Canva طابق Tajawal وAmiri بخطوطه. |
| **النمط صورة واحدة** | `background-repeat` ببلاطة 96px عاد **نحو مئتي مستطيل منفصل**. استيراد ينجح ويترك تصميمًا لا يُحتمل. |
| **ضمّن النمط data URI** | `raw` يقدّم SVG كـ`text/plain` فلا يرسمه المتصفّح — أول تصميم عاد بلا نمط أصلًا. |
| **العرض بالبكسل لا بـ`ch`** | `ch` تُحسب بالخط المحمَّل وقت التخطيط؛ والخط لم يكن قد وصل، ففاضت الفقرة خارج اللوحة. |
| **ارتفاع سطر صريح على كل نصّ** | التذييل ورث `normal` فجاء **١٫١٧** وقصّ نزلاته — المؤلِّف يخالف قاعدة الإضافة نفسها. |

`lintForImport` يفرض هذه كلها. لا تلتفّ عليها.

## ما لا يفعله هذا

- **لا يرسم صورًا.** لصورة بطل استعمل `generate-image` من Canva ثم `update_fill`
  على عنصر في التصميم المستورَد.
- **لا يضمن وفاء ١٠٠٪.** التدرّجات تُرسَّم صورًا، والشفافيات قد تُبسَّط. انظر
  إلى المصغّرة قبل أن تقول «تمّ».
- **لا يخترع علامة تجارية.** إن كان للمستخدم ألوان أو خطوط، خذها من
  `list-brand-kits` ولا تقترح غيرها.
