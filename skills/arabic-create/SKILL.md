# توليد تصميم عربي

## لماذا هذا ممكن أصلًا

عمليات Canva للرسم لا تصنع تدرّجًا ولا تغيّر خطًّا ولا ترسم نمطًا. **لكن
مستورِد HTML عندها يفعل الثلاثة**، لأنه يرسم الصفحة بنفسه ثم يعيدها طبقات
حقيقية: النصّ نصًّا قابلًا للتحرير، وخطوط Google مطابَقة بخطوط Canva.

## المسار كاملًا

```
كلام المستخدم → outline.json → make → نشر → استيراد → (MP4 للريل)
```

### ١. اكتب المخطّط

كل ما تحتاجه ملف واحد. لا تكتب `spec` يدويًا — لم يعد لذلك داعٍ.

```json
{
  "kicker": "قواعد الحضور",
  "iconName": "spark",
  "title": "٩ قواعد\nللهيبة والكاريزما",
  "lead": "الحضور لا يُفرَض بالصوت،\nبل يُبنى بتسع عادات صامتة.",
  "items": [
    { "title": "التقدير الداخلي", "body": "الهيبة تبدأ من احترامك\nالحقيقي لذاتك." }
  ],
  "closing": "الهيبة ليست قناعًا تلبسه،\nبل أثرًا تتركه حين تخرج.",
  "question": "أيّ قاعدة أصعب عليك؟\nاكتب رقمها 👇",
  "brand": "@kitabwbs · www.kitabwbs.com"
}
```

**اكسر الأسطر بنفسك بـ`\n`.** Canva يخطّط الصفحة بخطّ ثم يستبدل خطّه، فسطرٌ
وسعه التخطيط يفيض بعد الاستبدال. ما تريده سطرًا، اكتبه سطرًا.

**اكتب عربيًا لا مترجَمًا.** عنوان من كلمتين أقوى من جملة. تجنّب «نحن نقدم لكم
أفضل الحلول».

`iconName`: `tree` · `rose` · `hand` · `spark` · `quote`

### ٢. اختر المظهر

| | المتاح |
|---|---|
| `--format` | `reel` `story` `post` `square` `carousel` `cover` |
| `--palette` | `midnight` `paper` `sand` `ink` `sea` `olive` `plum` `clay` `steel` `mint` |
| `--pairing` | `editorial` `modern` `civic` `kufic` `clean` `classic` |
| `--pattern` | `none` `girih` `zellij` `rays` |
| `--layout` | `cover` `list` `quote` `stat` `closing` |

نحو **١٢٠٠ تركيبة**، وكل لوحة مُثبَت تباينها على كل المقاسات قبل أن تُشحن.

اختر بما يخدم المحتوى: `midnight`+`kufic` لمحتوى الهيبة، `paper`+`civic`
للنصائح العملية، `sand`+`editorial` للنصّ الأدبي. **إن لم يحدّد المستخدم فاعرض
ثلاثة اقتراحات مختلفة الزاوية لا مختلفة اللون فقط.**

### ٣. أمر واحد

```bash
node "${CLAUDE_PLUGIN_ROOT}/lib/cli.js" make outline.json \
  --reel --format=reel --palette=midnight --pairing=kufic --pattern=girih \
  --repo=<owner>/<repo> --branch=main --out=page.html
```

`--reel` يقسم تلقائيًا: غلاف + إطارات النقاط + خاتمة، والترقيم يتسلسل عبرها.
`--per-page=3` يضبط كم نقطة في الإطار (اثنتان = ريل أطول وأبطأ إيقاعًا).

يُخرج JSON:

| المفتاح | المعنى |
|---|---|
| `ok` | جاهز للنشر |
| `pages` `bytes` | عدد الإطارات وحجم الصفحة |
| `look` | المظهر المستعمَل — احفظه ليمكن تكرار التصميم |
| `lint` | ما يرفضه المستورِد — **لا تنشر وفيه شيء** |
| `issues` | إخفاقات التباين ومقاسات دون الحد |
| `notes` | ما لاحظه المدقّق على نصّك |
| `publish.url` | الرابط الذي سيجلبه Canva |

**اقرأ `notes`.** المدقّق لا يغيّر نصًّا كتبتَه عمدًا — الحركات والكلمات
المشكوك فيها تُعرَض ولا تُطبَّق. إن أشار إلى خطأ حقيقي فعدّل المخطّط.

عند الفشل يخرج بحالة خطأ ويقول ما ينقص بالعربية. أصلح المخطّط وأعد.

### ٤. انشر

المستورِد يقبل رابط HTTPS عامًّا فقط، و`raw.githubusercontent.com` يصلح
مباشرةً رغم أنه يقدّم `text/plain` (مُختبَر) — فلا وسيط ولا مستضيف خارجي.

1. حدّد مستودعًا **عامًّا** (`get_me` ثم `search_repositories`). إن لم يوجد
   فأنشئه بـ`create_repository` باسم `arabic-design-published`، عامًّا.
2. `create_or_update_file` بمسار `publish.path` ومحتوى `page.html`.

المسار يحمل بصمة المحتوى، فكل نشرة رابط جديد — وهذا يتجاوز تخزين CDN المؤقّت.

> **قل هذا للمستخدم صراحةً**: الصفحة تصير **عامّة** على GitHub حتى يجلبها
> Canva. هذا لازم لأي مسار استيراد. احذفها بعد النجاح إن كان النصّ حسّاسًا.

### ٥. استورد وتحقّق

```
import-design-from-url(publish.url, name, intended_design_type)
read-design(design_id, filter: { fields: ["thumbnails"], thumbnail_pages: [1,2,…] })
```

**انظر إلى المصغّرات فعلًا** — لا تقل «تمّ» قبل ذلك.

### ٦. فيديو

```
export-design(design_id, { type: "mp4", quality: "vertical_1080p", export_quality: "pro" })
```

خمسة إطارات = **٢٥ ثانية**، ١٠٨٠×١٩٢٠، H.264.

**ما لا تستطيعه الواجهة، قله للمستخدم**: لا تحكّم في مدّة الإطار (خمس ثوانٍ
ثابتة)، ولا في الانتقالات، ولا حركة على العناصر، ولا صوت. هذا ريل بطاقات لا
موشن جرافيك. لإيقاع أبطأ: `--per-page=2`.

### ٧. اعرض واسأل

اعرض المصغّرات والروابط، واحفظ `look` في ردّك. ثم اسأل: لوحة أخرى؟ مقاس ثانٍ؟
نفس المخطّط بمقاس آخر = تغيير `--format` وحده.

## قواعد التأليف — كلٌّ منها إخفاق مقيس

| القاعدة | ما حدث حين خولفت |
|---|---|
| اربط الخطوط ولا تضمّنها | ٨٤٥KB → رُفض الاستيراد: «محتوى أكثر من اللازم» |
| النمط صورة واحدة | خلفية متكرّرة → **نحو مئتي مستطيل منفصل** |
| النمط data URI | `raw` يقدّم SVG نصًّا → تصميم بلا نمط |
| العرض بالبكسل لا `ch` | فقرة خارج اللوحة |
| ارتفاع سطر صريح | التذييل ورث `normal` = ١٫١٧ → قصّ نزلاته |
| اكسر أسطر المتن يدويًا | سطر وسعه التخطيط فاض بعد استبدال الخط |

`lint` يفرضها كلها. لا تلتفّ عليها.

## حين لا يتّسع المحتوى

**اقسمه، لا تصغّره.** ستّ بطاقات وخاتمة وسؤال قيست ٢٦١٨px على لوحة ١٩٢٠px.
`--reel` يقسم تلقائيًا؛ ولمنشور واحد قلّل النقاط أو انقلها إلى `carousel`.

الحدّ الأدنى لحجم النصّ العربي غير قابل للتفاوض: أي مقاس دونه يُرفع ويُبلَّغ
في `issues`.

## ما لا يفعله هذا

- **لا يرسم صورًا.** لصورة بطل: `generate-image` ثم `update_fill` على عنصر في
  التصميم المستورَد.
- **لا يضمن وفاء ١٠٠٪.** التدرّجات تُرسَّم صورًا والشفافيات قد تُبسَّط.
- **لا يخترع علامة تجارية.** إن كان للمستخدم ألوان أو خطوط فخذها من
  `list-brand-kits`.
- **لا يصحّح نصًّا كتبه صاحبه عمدًا.** يعرض الملاحظة ويترك القرار له.
