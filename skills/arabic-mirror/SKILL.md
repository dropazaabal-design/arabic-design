# انعكاس التخطيط لـ RTL

اقرأ `REFERENCE.md` §٥ (ما ينعكس وما لا ينعكس) قبل البدء.

تصحيح النص وحده لا يجعل التصميم عربيًا. إن بقي السهم يشير يمينًا والخطوة الأولى
يسارًا فالعين تقرأ عكس ما يقرأ العقل.

## القاعدة الحاكمة

**ما يحمل معنى اتجاهيًا ينعكس. ما يحمل هوية أو واقعًا لا ينعكس.**

| ينعكس | لا ينعكس |
|---|---|
| الأسهم والشيفرونات ورموز «التالي/السابق» | الشعارات والعلامات التجارية |
| تسلسل الخطوات وترقيمها | الصور الفوتوغرافية ووجوه الأشخاص |
| أشرطة التقدّم واتجاه امتلائها | رموز التشغيل والإيقاف والتسجيل |
| محاور الرسوم البيانية واتجاه الأعمدة | الساعات والخرائط والأعلام |
| النقاط الاستهلالية ومسافاتها البادئة | التواقيع ورموز QR والباركود |
| الخطوط الزمنية | **الأرقام نفسها — لا تُقلب أبدًا** |
| موضع الصورة مقابل النص | |
| ترتيب القراءة العام | |

## الخطوات

### ١. افتح معاملة واقرأ

```
read-design(design_id, open_transaction: true,
            filter: { fields: ["design_metadata","page_metadata","design_content","thumbnails"] })
```

الصور المصغّرة ليست اختيارية هنا: كثير من قرارات الانعكاس لا تُتّخذ إلا بالنظر.

### ٢. حلّل

```bash
node "${CLAUDE_PLUGIN_ROOT}/lib/cli.js" payload.json
```

خذ قسم `mirror`:

- `candidates[].verdict === "mirror"` — تصنيف واثق، مع `suggestion` جاهز.
- `candidates[].verdict === "ask"` — لم يُعرف. **لا تخمّن.** اعرضه على المستخدم.
- `readingOrder` — صفوف عناصر عربية تسلسلها يتقدّم يسارًا. هذه أخطر مشكلة في
  القائمة لأنها تقلب معنى التصميم لا شكله.

التصنيف يعتمد على `alt_text` و`name`. إن كانت فارغة فكل شيء `ask` — عندها
**انظر إلى الصورة المصغّرة** وصنّف بنفسك، ثم اعرض تصنيفك للتأكيد.

### ٣. اعرض الخطة قبل أي تعديل

```markdown
## خطة الانعكاس — <n> عنصر

### سأعكسها
| العنصر | الوصف | من | إلى | العملية |
|---|---|---|---|---|
| PB1-LB5 | سهم يشير يمينًا | left 300 | left 660 | `position_element` + `flip_media` |

### تسلسل خاطئ
| الصف | العناصر | المشكلة |
|---|---|---|
| 1 | PB1-LB3 (الخطوة ١، يسارًا) ← PB1-LB4 (الخطوة ٢) | في RTL تبدأ الخطوة ١ يمينًا |

### لن أعكسها
| العنصر | السبب |
|---|---|
| PB1-LB6 | شعار — الشعارات لا تنعكس |

### أحتاج قرارك
| العنصر | الوصف | السؤال |
|---|---|---|
| PB1-LB7 | (بلا وصف) | أهو عنصر اتجاهي أم صورة؟ |
```

### ٤. طبّق في دفعة واحدة لكل صفحة

```
edit-design(transaction_id, page_index: N, operations: [...], finalize: "keep_open")
```

**السهم يحتاج عمليتين**، لا واحدة:

```json
{ "type": "flip_media",       "locator_id": "PB1-LB5", "axis": "horizontal", "flipped": true }
{ "type": "position_element", "locator_id": "PB1-LB5", "top": 710, "left": 660 }
```

`flip_media` يقلب الرسم نفسه، و`position_element` ينقله إلى الجهة المقابلة.
`detect.mirrorX(element, pageWidth)` يحسب `left` الجديد:
`pageWidth - (left + width)`.

عنصر يُنقل بلا قلب (صندوق نصّ، صورة غير اتجاهية ضمن تخطيط ينعكس) يأخذ
`position_element` وحده. عنصر يُقلب بلا نقل (سهم في مركز الصفحة) يأخذ
`flip_media` وحده.

### ٥. تحقّق بصريًا ثم استأذن ثم احفظ

```
read-design(design_id, transaction_id, filter: { fields: ["thumbnails"] })
```

اعرض «قبل» و«بعد» جنبًا إلى جنب. **انظر إلى الناتج فعلًا** قبل أن تسأل: انعكاس
التخطيط يكسر المحاذاة والتداخل بسهولة أكثر من أي تعديل آخر.

ثم:

```
edit-design(transaction_id, finalize: "commit")   // بعد موافقة صريحة
edit-design(transaction_id, finalize: "cancel")   // عند الرفض
```

## ما يحتاج يدًا بشرية

أبلغ عنه ولا تحاوله:

- **الرسوم البيانية المرسومة كصورة واحدة.** لا يمكن عكس محاورها دون إعادة بنائها.
- **العناصر المجمّعة (groups)** التي يحتاج داخلها ترتيبًا مختلفًا عن ظاهرها.
- **التدرّجات والظلال الاتجاهية** — لا عملية لعكس اتجاه التدرّج.
- **الصور التي تحوي نصًا مطبوعًا داخلها.** قلبها يقلب النص.
- **أي عنصر انعكاسه يكسر المحاذاة مع عنصر لا ينعكس.**

## خطأ شائع

قلب **الصفحة كلها** بدل عناصرها. النتيجة نصّ مقلوب مرآتيًا وشعار معكوس. اعكس
عنصرًا عنصرًا، دائمًا.
