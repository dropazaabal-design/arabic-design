# الفيديو العربي

موصّل Canva لا يملك عملية حركة، ولا انتقال، ولا مدّة صفحة، ولا صوت. `arabic-reels`
تقول ذلك منذ البداية وتسلّم خطواتٍ يدويّة. هذه المهارة تغلق الفجوة بالطريق
الأمين الوحيد: **لا تحرّك تصميم Canva، بل تركّب أثرًا ثانيًا من الخطّة نفسها**،
إطارًا إطارًا.

| | تصميم Canva | فيديو Remotion |
|---|---|---|
| التحرير | عناصر مستقلّة قابلة للتعديل | مسطّح |
| الحركة | يدويّة (Animate) | من الخطّة، بالإطار |
| مدّة المشهد | افتراض Canva | بالضبط كما في الخطّة |
| الصوت | تضيفه بنفسك | مسار لكل مشهد |

**ليس أحدهما بديلًا عن الآخر**، والحالة تذكرهما منفصلين.

## الخطوات

### ١. ركّب المشروع

```bash
node lib/cli.js render reel.json --out=reel-video \
  --voice=voice/script.json --palette=midnight --pairing=civic
```

يكتب مشروعًا كاملًا: `src/timeline.json` (الخطّة بالإطارات)، والمشاهد، والحركة،
واللوحة والخطوط من `lib/recipes.js` نفسها التي يرسم منها الكاروسيل — فلا يفترق
الفيديو عن التصميم الذي وُلد بجانبه. و`plan.json` يسافر مع المشروع ليُقاس لاحقًا
بلا الجلسة التي صنعته.

**الخطوط تُنزَّل الآن لا وقت التركيب.** شريحة `arabic` من كل وزن تُحفظ في
`public/fonts/`. التركيب الذي يطلب خطًّا من الشبكة يسقط خلف جدار ناري أو في CI أو
خلف وكيل لا يعرفه المتصفّح — وفي العربية السقوط ليس زخرفة ناقصة: هو مربّعات
فارغة، أو خطّ بديل يرسم الحروف **مفكّكة**. وإن تعذّر التنزيل يرجع المشروع إلى
خطوط Google ويقول ذلك في الحالة وفي `README` المشروع.

**والوزن سُلَّم لا رقم.** الخطوط الثمانية لا تحمل الأوزان نفسها: أميري ٤٠٠ و٧٠٠
لا غير، وReem Kufi بلا ٩٠٠، وAlmarai بلا ٥٠٠. فكل خانة تنزل سلّمها حتى يجيب
وزن، والمشروع يسمّي **ما أجاب**. ووزنٌ لا يحمله الخطّ **يصطنعه كروم** صامتًا —
تغليظ غير متساوٍ يلطّخ الوصلات العربية. وما استقرّ دون أوّل طلبه يُذكر في
`fonts.settled`: مع Reem Kufi يصير الرقم الضخم والعنوان كلاهما ٧٠٠، فيخفّ
التفاوت — قرار الخطّ، ويُقال.

### ٢. صدّر

```bash
cd reel-video && npm install && node render.mjs --out=out/reel.mp4
# ومعه متصفّح موجود بدل تنزيل ثانٍ:
node render.mjs --browser=/path/to/chrome-headless-shell
```

أو بخطوة واحدة: أضف `--run` إلى أمر `render` أعلاه.

### ٣. قِس

```bash
node lib/cli.js render --verify=reel-video/out/reel.mp4 --plan=reel.json \
                       --voice=voice/script.json
```

| البند | الحالات |
|---|---|
| المسار | remotion (ملف مستقلّ عن تصميم Canva) |
| المشروع | غير مركَّب · مركَّب (المجلّد، عدد المشاهد) |
| التثبيت | غير معروف · غير مثبَّت · مثبَّت |
| التصدير | لم يُصدَّر · مصدَّر (الملف، الترميز) |
| المقاس | غير متحقّق · متحقّق ١٠٨٠×١٩٢٠ · مخالف |
| المدّة | غير متحقّقة · متحقّقة · مخالفة (بالفرق) |
| الحركة | **مركَّبة من الخطّة** (عدد العناصر) |
| توقيت المشاهد | متحقّق بالبناء · غير متحقّق |
| الصوت | لا شيء · مخطّط · موجود في الملف · غائب عن الملف |

«الحركة» هنا هي السطر الوحيد الذي لا يستطيع تصدير MP4 من Canva أن يكسبه: المشهد
`Sequence` بطول محسوب، والحركة `interpolate`/`spring` تبدأ عند إطار معروف.

**فرق المدّة ليس خطأً.** مجموع المشاهد في الخطّة أطول من التركيب بمقدار
الانتقالات: الانتقال **يتراكب** على المشهدين لا يُحشر بينهما. الحالة تذكر الفرق
بالثانية حتى لا يُقرأ تركيب صحيح كعطل.

## أربع قواعد عربية مبنيّة في كل مشروع

كلّ واحدة منها كسرت تصميمًا حقيقيًا من قبل:

1. **لا حركة على الحرف.** تقطيع الكلمة إلى حروف متحرّكة يلزمه صندوق لكل حرف،
   والصندوق يقطع الوصل: «مرحبا» ← «م ر ح ب ا»، ولا transform يعيدها. الحركة على
   العنصر، كما تخزّنها الخطّة.
2. **الخطّ يُنتظر.** `loadFont` يحجز التركيب حتى يصل الملف، فلا يُرسم الإطار صفر
   بخطّ بديل — وهو عطل صامت: الفيديو يخرج، والحروف خطأ.
3. **`direction: rtl` على كل صندوق**، لا محاذاة وحدها. الفرق يظهر على محرف واحد:
   مع `ltr` و`text-align: right` تذهب نقطة آخر الجملة إلى اليمين — الطرف الخطأ.
   ومعها `unicode-bidi: plaintext` ليأخذ سطرٌ لاتيني بالكامل اتجاهه بنفسه.
4. **الأرقام كما في الخطّة.** التصميم حسم بين ٠١٢ و012؛ تركيبٌ «يصلحها» يسلّم
   فيديو يخالف الكاروسيل الذي جاء منه.

## الصوت

مقاطع `arabic-voice` تُنسخ إلى `public/` ثم تُركَّب كل واحدة على مشهدها. ومقطعٌ
لم يصل لا يُكتب في التركيب أصلًا: `staticFile` يفشل وقت التصدير فشلًا قاطعًا بعد
إطارات، لا فجوةً صامتة. وما غاب يُذكر في `audio.missing`.
