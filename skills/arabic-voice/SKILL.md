# الصوت العربي

التعليق الصوتي ليس نصّ التصميم مقروءًا. بينهما طبقة لا يراها أحد حتى تُسمَع:

| في التصميم | في الأذن بلا معالجة |
|---|---|
| `U+200F` بعد الجملة | محرف يدخل مفردات النموذج |
| «٨٠٪» | رقم يُنطق خطأً أو يُقفَز |
| «@kitabwbs» | «آت كاي آي تي…» أو صمت |
| «ســلام» (تمطيط) | مدّ غير مقصود |

هذه المهارة تبني النصّ المنطوق، وتختار المحرّك، وتكتب الأمر، وتقيس الناتج.

## المحرّكان

| | **Habibi-TTS** | **NAMAA-Egyptian-TTS** |
|---|---|---|
| اللهجات | ١٢: MSA SAU UAE ALG IRQ EGY MAR OMN TUN LEV SDN LBY | المصرية وحدها |
| الأساس | F5-TTS | Chatterbox Multilingual |
| المقطع المرجعي | **لازم** مع نصّه | اختياري |
| التشكيل | لا يحتاجه | لا يحتاجه |
| تبديل اللغات | عربي+إنجليزي/فرنسي | لا |
| التردّد | ٢٤ كيلوهرتز | ٢٤ كيلوهرتز |
| الترخيص | الكود MIT؛ الأوزان: الموحّد وSAU وUAE بـCC-BY-NC-SA-4.0، والبقيّة Apache-2.0 | MIT كلّه |
| التثبيت | `pip install habibi-tts` | `pip install chatterbox-tts torchaudio huggingface-hub safetensors` |

**الاختيار آليّ:** المصرية على نماء إن كانت مثبّتة (مبنيّة لها، وMIT بالكامل)،
وما عداها على حبيبي. و`--commercial` يرفض الأوزان غير التجاريّة بدل أن يمرّرها
في ريل مموّل.

## الخطوات

### ١. انظر ما المتاح

```bash
node lib/cli.js voices --dialect=EGY --commercial
```

يُرجع المحرّكين بحدودهما، والمسار لهذه اللهجة، والترخيص، والسجلّ العدديّ.

### ٢. اكتب النصّ المنطوق

```bash
node lib/cli.js speak reel.json --dialect=EGY --out=voice
```

`reel.json` خطّة من `canva_build_reel`. المخرجات: `voice/script.json` (سطر لكل
مشهد مع تقديره)، و`voice/synth.sh` (الأوامر بالضبط)، و`voice/namaa_tts.py` إن كان
المحرّك نماء.

ما يجري على كل سطر، بهذا الترتيب:

1. **محارف الاتجاه تُنزع.** أولًا، لأنها تقع داخل الكلمات وتكسر كل نمط بعدها.
2. **التمطيط يُحذف**، والإيموجي كذلك.
3. **ما لا يُقرأ يخرج**: رابط، بريد، حساب، وسم، هاتف. ويُذكر كلّه في `dropped` —
   لا حذف صامت. `--handles=keep` يُبقي الحسابات إن أردتها منطوقة.
4. **الأرقام تصير كلمات.** نماء تقول عن نفسها إنّ «الأرقام تُنطق خطأً أحيانًا»،
   وحبيبي يقرأ الرقم كما وقع في بياناته. فلا يُرسَل رقم أصلًا.
5. **الفواصل تصير وقفات**: `…` و`—` وسطر جديد كلّها «،».

**ما يُقرأ من المشهد**: التمهيد، والرقم، والعنوان، والسطر الداعم، والاقتباس —
بهذا الترتيب. وشارات الخاتمة (`actions`: «احفظه»، «تابعنا @…») **لا تُقرأ**:
العين تقرؤها، وصوتٌ يقولها يكرّر العنوان ثم يتهجّى حسابًا.

السجلّ العدديّ يتبع اللهجة: المصرية «اتنين» و«تلتمية» و«تلات ساعات»، وما عداها
الفصحى «اثنان» و«ثلاثمئة». وصيغة العدّ المصرية (٣–١٠ قبل معدودها) مطبَّقة؛
ومطابقة الجنس في الفصحى (ثلاث ساعات / ثلاثة أيام) **ليست** مطبَّقة لأنها تحتاج
جنس المعدود — تُترك صيغة الإفراد ويُقال ذلك.

### ٣. ولّد

```bash
# حبيبي: المقطع المرجعي ونصّه معًا — بلا النصّ ينحرف الاستنساخ
node lib/cli.js speak reel.json --dialect=LEV \
  --ref-audio=ref/lev.mp3 --ref-text="النصّ المنطوق في هذا المقطع حرفًا بحرف" \
  --out=voice --run

# نماء: بلا مرجع، أو بمرجع لنقل النبرة
node lib/cli.js speak reel.json --dialect=EGY --out=voice --run
```

بلا `--run` تُكتب الأوامر ولا تُنفَّذ — خذها إلى آلة فيها GPU. و`--run` لا يشغّل
إلا محرّكًا ثبت وجوده بالفحص.

### ٤. المدّة: اقطع كلمات ولا تسرّع الصوت

لكل مشهد مدّة في الخطّة، ولكل سطر تقدير. إن تجاوز التقدير المدّة فالحُكم
`overflow` ومعه عدد الكلمات التي تُحذف.

**حبيبي يملك `--speed` و`--fix_duration`، وهذه المهارة ترفضهما.** للسبب نفسه
الذي يمنع تصغير الخط لإدخال عنوان طويل: مشهد لا يتّسع فيه الصوت نصُّه أطول من
اللازم. اختصره.

### ٥. قِس

كل مقطع يُقرأ بـffprobe بعد توليده: موجود؟ تردّده؟ طوله؟ وأمر خرج بصفر ليس
صوتًا. ثم:

| البند | الحالات |
|---|---|
| المحرّك | غير مختار · مختار (الاسم، اللهجة، النسخة، الترخيص) |
| النصّ | لا شيء · مكتوب (تقدير من الكلمات، لا من ملف) |
| الملفات | لم تُولَّد · جزئيًا (كم من كم) · مولَّدة |
| التردّد | غير متحقّق · متحقّق · مختلط · مخالف للمتوقّع |
| المدّة | غير متحقّقة · مقيسة (ومعها التقدير للمقارنة) |
| كل مشهد | غير مقيس · يتّسع · يتجاوز المشهد (بكم) |

## حدود مذكورة لا مخفيّة

- **`--dialect MAR` يرفضها سطر أوامر حبيبي اليوم.** الـassert في `infer_cli.py`
  يكرّر IRQ ويُسقط MAR، مع أنّ `dialect_id_map` تعرّفها. العلاج: الواجهة
  الرسومية `habibi-tts_infer-gradio`، أو `--dialect UNK` مع مقطع مرجعي مغربي —
  والاستنساخ يحمل اللهجة. لا نخترع معاملًا يسقط مع أول إصدار.
- **لا نسخة متخصّصة** لـMAR وOMN وTUN وLEV وSDN وLBY: النموذج الموحّد يغطّيها،
  وترخيصه CC-BY-NC-SA-4.0.
- **«ق» قد تسقط** في نطق نماء المصري. لا علاج هنا؛ راجع المقطع بأذنك.
- **إعراب الأرقام غير مطبَّق**: «٨٠٪» تُقرأ «ثمانون في المئة» دائمًا، ولو اقتضى
  السياق «ثمانين». صيغة الإفراد مفهومة، والتخمين النحوي ليس أدقّ منها.
- **التشكيل يُترك كما كتبه صاحبه.** فإن كان بعض الكلمات مشكولًا وبعضها لا
  — علامةُ مولّد — يُبلَّغ ولا يُغيَّر. `--no-harakat` يزيله (والشدّة تبقى: حذفها
  يفقد التضعيف الذي يسمعه النموذج).

## ثمّ

الصوت وحده ليس ريلًا. `arabic-video` يركّب المقاطع على المشاهد في فيديو حقيقي:

```bash
node lib/cli.js render reel.json --voice=voice/script.json --out=reel-video --run
```
